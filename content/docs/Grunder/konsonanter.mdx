## Kärnan på en halv minut

De viktigaste reglerna för tyska konsonanter:

1. **ch-ljudet har två varianter**:
   * **Ich-ljudet [ç]**: mjukt väsande framme vid gommen, efter mjuka vokaler (**e, i, ä, ö, ü**) och diftongerna **ei, eu** samt efter konsonanterna **l, n, r** (<span lang="de">ich</span>, <span lang="de">echt</span>, <span lang="de">Milch</span>).
   * **Ach-ljudet [x]**: raspande i svalget, endast efter de hårda bakre vokalerna **a, o, u** och diftongen **au** (<span lang="de">Buch</span>, <span lang="de">Nacht</span>, <span lang="de">doch</span>).
2. **sp- och st- i ordens början**:
   * Uttalas alltid som **schp-** och **scht-** (<span lang="de">Sport</span> [ʃpɔʁt], <span lang="de">Stadt</span> [ʃtat]).
3. **Bokstaven Z uttalas alltid [ts]**:
   * Aldrig surrande engelskt z (<span lang="de">Zeit</span> = *tsajt*, <span lang="de">Zimmer</span> = *tsimmer*).
4. **Auslautverhärtung (tonlöshet i ordslut)**:
   * **b, d, g** i slutet av ord uttalas tonlöst som **p, t, k** (<span lang="de">Tag</span> låter *taak*, <span lang="de">und</span> låter *unt*, <span lang="de">ab</span> låter *ap*).

## 1. Ich-ljudet [ç] vs. Ach-ljudet [x]

Regeln är helt fonetiskt logisk: munnen väljer det ljud som ligger närmast den föregående vokalen!

| Typ | Föregående ljud | Exempel | IPA | Betydelse |
| :--- | :--- | :--- | :--- | :--- |
| **Ich-ljud [ç]** (framme i munnen) | **i, e, ä, ö, ü** | <AudioButton text="ich" ipa="ɪç" /> | [ɪç] | jag |
| | | <AudioButton text="echt" ipa="ɛçt" /> | [ɛçt] | äkta, verkligen |
| | | <AudioButton text="Mädchen" ipa="ˈmɛːtçən" /> | [ˈmɛːtçən] | flicka |
| | | <AudioButton text="Bücher" ipa="ˈbyːçɐ" /> | [ˈbyːçɐ] | böcker |
| | diftongerna **ei, eu** | <AudioButton text="leicht" ipa="laɪ̯çt" /> | [laɪ̯çt] | lätt |
| | efter **l, n, r** | <AudioButton text="Milch" ipa="mɪlç" /> | [mɪlç] | mjölk |
| | | <AudioButton text="durch" ipa="dʊʁç" /> | [dʊʁç] | genom |
| **Ach-ljud [x]** (bak i svalget) | **a, o, u** | <AudioButton text="Nacht" ipa="naxt" /> | [naxt] | natt |
| | | <AudioButton text="noch" ipa="nɔx" /> | [nɔx] | ännu |
| | | <AudioButton text="Buch" ipa="buːx" /> | [buːx] | bok |
| | diftongen **au** | <AudioButton text="auch" ipa="aʊ̯x" /> | [aʊ̯x] | också |

## 2. sp- och st- i ordets början

I början av ord eller stavelser uttalas bokstavskombinationerna **sp** och **st** med ett tydligt sch-ljud:

* <span lang="de">**Sport**</span> [ʃpɔʁt] — idrott
* <span lang="de">**sprechen**</span> [ˈʃpʁɛçn̩] — tala
* <span lang="de">**Stadt**</span> [ʃtat] — stad
* <span lang="de">**Straße**</span> [ˈʃtʁaːsə] — gata
* <span lang="de">**stehen**</span> [ˈʃteːən] — stå

*Obs!* Mitt i eller i slutet av ord uttalas de däremot som vanligt [sp] och [st]:
* <span lang="de">**Fenster**</span> [ˈfɛnstɐ] — fönster (vanligt s + t)
* <span lang="de">**Wespe**</span> [ˈvɛspə] — geting (vanligt s + p)

## 3. De olika s-ljuden: S, SS, ß och Z

| Skrivsätt | Placering | Ljud | Exempel | Betydelse |
| :--- | :--- | :--- | :--- | :--- |
| **s-** (före vokal) | I början av ord/stavelse | **Tonande [z]** (som engelskt *zoo*) | <span lang="de">die Sonne</span> [ˈzɔnə] | sol |
| | | | <span lang="de">sieben</span> [ˈziːbn̩] | sju |
| **-s** (i ordslut) | Slutet av ord | **Tonlöst [s]** | <span lang="de">das Glas</span> [glaːs] | glas |
| **ss** | Efter kort vokal | **Tonlöst [s]** | <span lang="de">das Wasser</span> [ˈvasɐ] | vatten |
| **ß** | Efter lång vokal/diftong | **Tonlöst [s]** | <span lang="de">die Straße</span> [ˈʃtʁaːsə] | gata |
| **z** | Var som helst | **[ts]** | <span lang="de">der Zug</span> [tsuːk] | tåg |

## 4. Auslautverhärtung (Tonlöshet i ordslut)

I tyskan förlorar konsonanterna **b, d, g, v** sin stämbandston när de står sist i ett ord eller en stavelse:

* **-d** låter som **t**:
  * <span lang="de">**und**</span> [ʊnt] (låter *unt*)
  * <span lang="de">**Bild**</span> [bɪlt] (låter *bilt*)
* **-b** låter som **p**:
  * <span lang="de">**ab**</span> [ap] (låter *ap*)
  * <span lang="de">**Urlaub**</span> [ˈuːɐ̯laʊ̯p] (låter *ur-laup*)
* **-g** låter som **k**:
  * <span lang="de">**Tag**</span> [taːk] (låter *taak*)
  * <span lang="de">**Zug**</span> [tsuːk] (låter *tsook*)

Men så fort ordet böjs och en vokal följer, återvänder det tonande ljudet:
* <span lang="de">der Tag</span> [taːk] -> <span lang="de">die Tage</span> [ˈtaːgə]

---

## 5. Det tyska R-ljudet

I standardtyska (*Hochdeutsch*) uttalas **r** vanligtvis som ett bakre svalgljud [ʁ] (likt sydsvenskt eller franskt r):
* I början av ord: <span lang="de">**rot**</span> [ʁoːt], <span lang="de">**Reise**</span> [ˈʁaɪ̯zə]
* Efter konsonant: <span lang="de">**Brot**</span> [bʁoːt], <span lang="de">**Frau**</span> [fʁaʊ̯]

I obetonade stavelser (särskilt ändelsen **-er**) vokaliseras r till ett dämpat a-liknande ljud [ɐ]:
* <span lang="de">**Wasser**</span> [ˈvasɐ]
* <span lang="de">**Mutter**</span> [ˈmʊtɐ]
* <span lang="de">**Lehrer**</span> [ˈleːʁɐ]

*Rullande tungspets-r [r] förekommer också i södra Tyskland, Österrike och Schweiz och är fullt accepterat.*

## 10 autentiska exempel

1. <span lang="de">Ich spreche heute mit dem Arzt.</span>  
   *(Ich-ljud i ich och spreche, sp- i början som schp, z i Arzt som ts.)*
2. <span lang="de">Guten Tag, wie geht es Ihnen?</span>  
   *(Auslautverhärtung på Tag [taːk], tonande s i Sie.)*
3. <span lang="de">Die Straße ist sehr lang.</span>  
   *(Sch-ljud i Straße [ʃtʁaːsə], Eszett efter långt a.)*
4. <span lang="de">Wir haben ein schönes Zimmer im Zentrum.</span>  
   *(z i Zimmer och Zentrum uttalas [ts].)*
5. <span lang="de">Das Buch liegt auf dem Tisch.</span>  
   *(Ach-ljud i Buch [buːx], sch i Tisch.)*
6. <span lang="de">Kommst du aus der Schweiz?</span>  
   *(sp/st och sch-kombinationer.)*
7. <span lang="de">Er trinkt kalte Milch.</span>  
   *(Ich-ljud efter l i Milch [mɪlç].)*
8. <span lang="de">Wir fahren mit dem Zug nach Salzburg.</span>  
   *(Zug slutar på [k], Salzburg har z [ts] och g [k].)*
9. <span lang="de">Das ist wirklich nicht einfach.</span>  
   *(ch efter i är ich-ljud, efter a i einfach är ach-ljud.)*
10. <span lang="de">Haben Sie am Wochenende Zeit?</span>  
    *(Tonande s i Sie, z i Zeit [tsaɪ̯t].)*
