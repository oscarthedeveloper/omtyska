## Kärnan på en halv minut

I tyskan finns tre huvudregler för stor begynnelsebokstav (*Großschreibung*):

1. **ALLA substantiv** skrivs med stor bokstav, var som helst i meningen:
   * <span lang="de">der **Hund**</span>, <span lang="de">das **Buch**</span>, <span lang="de">die **Freiheit**</span>, <span lang="de">die **Liebe**</span>
2. **Substantiveringar** (ord från andra ordklasser som används som substantiv):
   * Verb: <span lang="de">das **Essen**</span> (maten/ätandet), <span lang="de">beim **Lernen**</span> (under inlärningen)
   * Adjektiv: <span lang="de">das **Gute**</span> (det goda), <span lang="de">etwas **Neues**</span> (något nytt)
3. **Det artiga tilltalet (Sie / Ihr / Ihnen)**:
   * Skrivs alltid med stor bokstav för att skilja sig från det vanliga tredje person *sie* (hon/de):
   * <span lang="de">Wie geht es **Ihnen**?</span> (Hur mår ni?) kontra <span lang="de">Wie geht es **ihnen**?</span> (Hur mår de?)

## 1. Substantiv vs. Adjektiv: Den svenska fällan

I svenskan skriver vi veckodagar, månader, språk och nationaliteter med liten bokstav:
* *på måndag, i juli, jag talar tyska, en tysk bil*

I tyskan måste du skilja mellan substantiv och adjektiv:

| Kategori | Tyska (Stor bokstav vid substantiv) | Svenska |
| :--- | :--- | :--- |
| **Veckodagar** | <span lang="de">am **Montag**</span>, <span lang="de">am **Freitag**</span> | på måndag, på fredag |
| **Månader** | <span lang="de">im **Januar**</span>, <span lang="de">im **August**</span> | i januari, i augusti |
| **Tidpunkter** | <span lang="de">heute **Abend**</span>, <span lang="de">am **Morgen**</span> | i kväll, på morgonen |
| **Språk som substantiv** | <span lang="de">Ich lerne **Deutsch**.</span> | Jag lär mig tyska. |
| **Språk/ursprung som adjektiv** | <span lang="de">Das ist ein **deutsches** Auto.</span> | Det är en tysk bil. |

*Undantag:* När ett tidsuttryck är ett adverb med ändelsen **-s**, skrivs det med liten bokstav:
* <span lang="de">am Montag</span> (substantiv: på måndag) vs. <span lang="de">montags</span> (adverb: på måndagarna / varje måndag).
* <span lang="de">heute Abend</span> (i kväll) vs. <span lang="de">abends</span> (på kvällarna).

---

## 2. Substantiveringar (När andra ord blir substantiv)

Varje tyskt ord kan förvandlas till ett substantiv. Då får det neutralt genus (<span lang="de">das</span>) och **stor bokstav**:

### 1. Infinitiv av verb -> Substantiv
* <span lang="de">leben</span> (att leva) -> <span lang="de">**das Leben**</span> (livet)
* <span lang="de">essen</span> (att äta) -> <span lang="de">**das Essen**</span> (maten)
* <span lang="de">schwimmen</span> -> <span lang="de">Ich gehe zum **Schwimmen**.</span> (Jag går och simmar.)

### 2. Adjektiv efter obestämda pronomen (etwas, nichts, viel, wenig)
* <span lang="de">neu</span> (ny) -> <span lang="de">Ich habe etwas **Neues** gelernt.</span> (något nytt)
* <span lang="de">interessant</span> -> <span lang="de">Gibt es etwas **Interessantes**?</span> (något intressant)
* <span lang="de">gut</span> -> <span lang="de">Wir wünschen Ihnen alles **Gute**!</span> (allt gott)

---

## 3. Artigt tilltal: Sie och Ihr

I tyskan är artighetsformen levande i arbetslivet, i butiker och mot personer man inte känner:

| Artigt tilltal (Alltid stor bokstav) | Vanligt tilltal / Tredje person (Liten bokstav) |
| :--- | :--- |
| <span lang="de">Können **Sie** mir helfen?</span> *(Kan Ni hjälpa mig?)* | <span lang="de">Können **sie** mir helfen?</span> *(Kan de hjälpa mig?)* |
| <span lang="de">Ist das **Ihr** Koffer?</span> *(Är det Er resväska?)* | <span lang="de">Ist das **ihr** Koffer?</span> *(Är det hennes resväska?)* |
| <span lang="de">Ich danke **Ihnen**.</span> *(Jag tackar Er.)* | <span lang="de">Ich danke **ihnen**.</span> *(Jag tackar dem.)* |

## 10 autentiska exempel

1. <span lang="de">Am **Montag** habe ich einen **Termin** beim **Arzt**.</span>  
   *(Tre substantiv med stor bokstav: Montag, Termin, Arzt.)*
2. <span lang="de">Ich spreche sehr gut **Deutsch** und ein bisschen **Englisch**.</span>  
   *(Språknamn som substantiv stavas med stor bokstav.)*
3. <span lang="de">Das **Buch** liegt auf dem **Tisch** im **Wohnzimmer**.</span>  
   *(Alla substantiv i hela satsen stavas med versal.)*
4. <span lang="de">Haben **Sie** schon etwas **Neues** gehört?</span>  
   *(Artigt Sie + substantiverat adjektiv Neues efter etwas.)*
5. <span lang="de">Wir treffen uns heute **Abend** um acht **Uhr**.</span>  
   *(Tidpunkten Abend och klockslaget Uhr är substantiv.)*
6. <span lang="de">Das **Schwimmen** im **See** macht großen **Spaß**.</span>  
   *(Substantiverat verb Schwimmen + See + Spaß.)*
7. <span lang="de">Er liest eine **deutsche** Zeitung.</span>  
   *(deutsche är adjektiv och skrivs med liten bokstav; Zeitung är substantiv.)*
8. <span lang="de">Darf ich **Ihre** Telefonnummer haben?</span>  
   *(Artigt possessivt pronomen Ihre med stor bokstav.)*
9. <span lang="de">Ich wünsche dir alles **Liebe** zum **Geburtstag**!</span>  
   *(alles Liebe med versalt L + Geburtstag.)*
10. <span lang="de">Die **Kinder** spielen **nachmittags** draußen.</span>  
    *(Kinder är substantiv; nachmittags är tidsadverb och stavas med gemen.)*
