## Kärnan på en halv minut

**Dativ** svarar på frågan **Wem?** (Åt vem? Till vem?):

| Genus / Numerus | Bestämd artikel | Obestämd artikel | Negerande form | Exempel |
| :--- | :--- | :--- | :--- | :--- |
| **Maskulinum** | <span lang="de">**dem**</span> | <span lang="de">**einem**</span> | <span lang="de">**keinem**</span> | <span lang="de">dem Mann / einem Mann</span> |
| **Femininum** | <span lang="de">**der**</span> | <span lang="de">**einer**</span> | <span lang="de">**keiner**</span> | <span lang="de">der Frau / einer Frau</span> |
| **Neutrum** | <span lang="de">**dem**</span> | <span lang="de">**einem**</span> | <span lang="de">**keinem**</span> | <span lang="de">dem Kind / einem Kind</span> |
| **Plural** | <span lang="de">**den (+n)**</span> | <span lang="de">– (+n)</span> | <span lang="de">**keinen (+n)**</span> | <span lang="de">den Kindern / keinen Freunden</span> |

<div className="callout callout-info">
  <div className="callout-title">💡 Dativens två superregler för artiklar</div>
  <ul>
    <li><strong>Maskulinum och Neutrum är tvillingar:</strong> Båda heter alltid <span lang="de"><strong>dem</strong></span> / <span lang="de"><strong>einem</strong></span>!</li>
    <li><strong>Femininum lånar r-ändelsen:</strong> Den feminina artikeln <em>die</em> blir <span lang="de"><strong>der</strong></span> / <span lang="de"><strong>einer</strong></span> i dativ.</li>
    <li><strong>Plural får dubbelt n:</strong> Artikeln blir <span lang="de"><strong>den</strong></span> och substantivet får ändelsen <strong>-n</strong>: <span lang="de">den Hunden</span>, <span lang="de">den Tischen</span>.</li>
  </ul>
</div>

## 1. Dativ som mottagare (Indirekt objekt)

När en mening har två objekt anger dativ vem som tar emot saken, medan ackusativ anger vad som ges:

```
   Subjekt          Verb        Dativ (Mottagare)     Ackusativ (Saken)
   ----------------------------------------------------------------------
   Der Vater        gibt        dem Sohn              einen Apfel.
   Die Lehrerin     schenkt     der Schülerin         ein Buch.
   Ich              schreibe    meinen Eltern         einen Brief.
```

---

## 2. Verb som ALLTID styr dativ

I svenskan ser verbet *hjälpa* ut som ett vanligt verb med direkt objekt (*"Jag hjälper honom"*).  
I tyskan är det däremot ett **dativverb**:

| Tyskt dativverb | Svensk betydelse | Exempel med dativ |
| :--- | :--- | :--- |
| <span lang="de">**helfen**</span> | hjälpa | <span lang="de">Ich helfe **dem Mann**.</span> *(inte den Mann!)* |
| <span lang="de">**danken**</span> | tacka | <span lang="de">Wir danken **Ihnen**.</span> *(Vi tackar Er.)* |
| <span lang="de">**gratulieren**</span> | gratulera | <span lang="de">Ich gratuliere **dir** zum Geburtstag!</span> |
| <span lang="de">**gehören**</span> | tillhöra | <span lang="de">Das Auto gehört **meinem Vater**.</span> |
| <span lang="de">**gefallen**</span> | behaga / tilltala | <span lang="de">Berlin gefällt **mir** sehr gut.</span> |
| <span lang="de">**passen**</span> | passa (storlek/tid) | <span lang="de">Die Hose passt **dem Kind** nicht.</span> |
| <span lang="de">**schmecken**</span> | smaka gott för | <span lang="de">Die Suppe schmeckt **den Gästen**.</span> |
| <span lang="de">**antworten**</span> | svara (en person) | <span lang="de">Bitte antworte **mir** bald!</span> |

---

## 3. Opersonliga dativuttryck: "Mir ist kalt"

En av de roligaste och viktigaste skillnaderna mellan svenska och tyska är hur man uttrycker kroppsliga tillstånd:

| Felaktig svensk översättning | Korrekt tyska med dativ | Betydelse på svenska |
| :--- | :--- | :--- |
| ❌ *Ich bin kalt.* | ✅ <span lang="de">**Mir ist kalt.**</span> | Jag fryser. *(Ich bin kalt betyder "jag är en känslokall person" eller "jag är likstel")* |
| ❌ *Ich bin warm.* | ✅ <span lang="de">**Mir ist warm.**</span> | Jag är varm / svettas. |
| ❌ *Ich bin schlecht.* | ✅ <span lang="de">**Mir ist schlecht.**</span> | Jag mår illa. *(Ich bin schlecht betyder "jag är en dålig människa")* |
| ❌ *Ich bin langweilig.* | ✅ <span lang="de">**Mir ist langweilig.**</span> | Jag har tråkigt. *(Ich bin langweilig betyder "jag är en tråkig person")* |

## 10 autentiska exempel

1. <span lang="de">Kannst du **meiner Mutter** bitte beim Tragen helfen?</span>  
   *(helfen styr dativ: meiner Mutter.)*
2. <span lang="de">Ich gebe **dem Kellner** ein gutes Trinkgeld.</span>  
   *(dem Kellner är mottagaren i dativ maskulinum.)*
3. <span lang="de">Wie geht es **deinem Bruder**?</span>  
   *(Dativ i hälsningsfras: deinem Bruder.)*
4. <span lang="de">Das neue Haus gefällt **den Nachbarn** sehr.</span>  
   *(gefallen styr dativ plural: den Nachbarn.)*
5. <span lang="de">Wir danken **dem Arzt** von ganzem Herzen.</span>  
   *(danken styr dativ: dem Arzt.)*
6. <span lang="de">Der Schlüssel gehört **diesem Herrn** hier.</span>  
   *(gehören styr dativ: diesem Herrn.)*
7. <span lang="de">Zieh eine Jacke an, sonst wird **dir** kalt!</span>  
   *(Tillstånd med dativ: dir wird kalt.)*
8. <span lang="de">Der Pullover passt **dem Kind** leider nicht mehr.</span>  
   *(passen styr dativ: dem Kind.)*
9. <span lang="de">Er antwortet **seinem Chef** immer sehr höflich.</span>  
   *(antworten styr dativ: seinem Chef.)*
10. <span lang="de">Ich gratuliere **euch** zur bestandenen Prüfung!</span>  
    *(gratulieren med dativplural: euch.)*
