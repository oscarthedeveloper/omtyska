## Kärnan på en halv minut

Ett verbs **rektion** är dess grammatiska makt att kräva ett visst kasus hos sitt objekt:

```
1. VERB MED ACKUSATIV (ca 85% av alla verb):
   sehen, kaufen, haben, lieben, trinken, lesen, fragen, suchen
   "Ich sehe DEN Mann."   "Ich trinke EINEN Kaffee."

2. VERB MED DATIV (Mottagare, nytta/skada, relation):
   helfen, danken, gefallen, gehören, glauben, gratulieren, schmecken, passen
   "Ich helfe DEM Mann."  "Das Buch gefällt MIR."

3. VERB MED BÅDE DATIV OCH ACKUSATIV (Ditransitiva verb):
   geben, schenken, zeigen, schicken, erklären, empfehlen
   "Ich gebe  [DEM FREUND] (Dativ)  [DAS BUCH] (Ackusativ)."
```

---

## 1. Den livsviktiga Dativ-listan

Dessa vanliga verb tar **aldrig ackusativ**. De styr alltid dativ i tyskan:

| Verb | Svensk betydelse | Autentiskt exempel |
| :--- | :--- | :--- |
| **helfen** | hjälpa | <span lang="de">Kannst du **mir** bitte helfen?</span> |
| **danken** | tacka | <span lang="de">Ich danke **Ihnen** herzlich.</span> |
| **gefallen** | behaga / gilla | <span lang="de">Die Stadt gefällt **meinen Eltern**.</span> |
| **gehören** | tillhöra / ägas av | <span lang="de">Das Auto gehört **meinem Bruder**.</span> |
| **glauben** | tro (på en person) | <span lang="de">Ich glaube **dir** kein Wort!</span> |
| **gratulieren** | gratulera | <span lang="de">Wir gratulieren **dem Geburtstagskind**.</span> |
| **passen** | passa (storlek/tid) | <span lang="de">Der Termin passt **mir** gut.</span> |
| **schmecken** | smaka (gott för) | <span lang="de">Die Suppe schmeckt **den Gästen**.</span> |
| **antworten** | svara (en person) | <span lang="de">Er antwortet **dem Lehrer** nicht.</span> |
| **fehlen** | saknas / fattas | <span lang="de">Du fehlst **mir** so sehr.</span> |

```
Subjekt-objekt-fällan vid "gefallen":
  På svenska säger vi: "Jag gillar filmen" (Jag = subjekt).
  På tyska säger man:   "Der Film gefällt MIR" (Filmen = subjekt, mir = dativobjekt)!
```

---

## 2. Två objekt: Dativ för personen, Ackusativ för saken

När ett verb har två objekt svarar dativen på *Åt vem?* och ackusativen på *Vad?*:

* <span lang="de">Der Vater schenkt **seinem Sohn** *(Dativ)* **ein Fahrrad** *(Ackusativ)*.</span>
* <span lang="de">Der Kellner bringt **den Gästen** *(Dativ)* **die Speisekarte** *(Ackusativ)*.</span>
* <span lang="de">Können Sie **mir** *(Dativ)* **den Weg** *(Ackusativ)* erklären?</span>

---

## 3. Sällsynta verb med Genitiv (Högtidligt språk)

En liten grupp verb styr **genitiv** i stället för ackusativ eller dativ. De förekommer främst i officiella sammanhang, litteratur och juridik:

* **gedenken** *(hedra minnet av)*:  
  <span lang="de">Wir gedenken **der Opfer** des Krieges.</span> *(Vi hedrar offrens minne.)*
* **sich rühmen** *(skryta med)*:  
  <span lang="de">Er rühmt sich **seiner großen Erfolge**.</span>
* **beschuldigen** *(anklaga för något)*:  
  <span lang="de">Man beschuldigte ihn **des Diebstahls**.</span> *(Man anklagade honom för stöld.)*

I modernt vardagsspråk ersätts de flesta genitivverb med prepositionsuttryck.

---

## 10 autentiska exempel

1. <span lang="de">Der Arzt hilft **dem verletzten Sportler** sofort.</span>  
   *(helfen styr dativ: dem Sportler.)*
2. <span lang="de">Ich habe gestern **einen interessanten Artikel** gelesen.</span>  
   *(lesen styr ackusativ: einen Artikel.)*
3. <span lang="de">Die neue Brille steht **dir** wirklich ausgezeichnet!</span>  
   *(stehen = klä någon, styr dativ: dir.)*
4. <span lang="de">Wie gefällt **Ihnen** unser neues Bürogebäude?</span>  
   *(gefallen styr dativ: Ihnen.)*
5. <span lang="de">Der Lehrer erklärt **den Schülern** die schwere Grammatikregel.</span>  
   *(den Schülern dativ + die Regel ackusativ.)*
6. <span lang="de">Das Buch gehört nicht **mir**, sondern **meiner Schwester**.</span>  
   *(gehören styr dativ: mir, meiner Schwester.)*
7. <span lang="de">Ich vertraue **meinem besten Freund** vollkommen.</span>  
   *(vertrauen styr dativ: meinem Freund.)*
8. <span lang="de">Der Polizist fragte **den Autofahrer** nach seinen Papieren.</span>  
   *(fragen styr ackusativ: den Autofahrer.)*
9. <span lang="de">Das Essen schmeckt **uns allen** hervorragend.</span>  
   *(schmecken styr dativ: uns allen.)*
10. <span lang="de">Die Regierung gedenkt **der Gefallenen**.</span>  
    *(gedenken styr genitiv: der Gefallenen.)*
