## Kärnan på en halv minut

Det finns fem centrala prepositioner i tyskan som **undantagslöst styr ackusativ**:

```
   DURCH · FÜR · GEGEN · OHNE · UM  (samt BIS)
```

Minnesramsa: **DOG-FU** (*Durch, Ohne, Gegen, Für, Um*).

Efter dessa prepositioner måste artikeln eller pronomenet stå i **ackusativ**:
* Maskulinum: <span lang="de">**den** / **einen** / **ihn**</span>
* Femininum: <span lang="de">**die** / **eine** / **sie**</span>
* Neutrum: <span lang="de">**das** / **ein** / **es**</span>
* Plural: <span lang="de">**die** / **keine** / **sie**</span>

---

## 1. De fem prepositionerna i detalj

| Preposition | Grundbetydelse | Exempel på tyska | Betydelse |
| :--- | :--- | :--- | :--- |
| <span lang="de">**durch**</span> | genom, med hjälp av | <span lang="de">Wir gehen durch **den Park**.</span> | Vi går genom parken. |
| | | <span lang="de">Er schaut durch **das Fenster**.</span> | Han tittar genom fönstret. |
| <span lang="de">**für**</span> | för, till, avsedd åt | <span lang="de">Das Geschenk ist für **meinen Bruder**.</span> | Presenten är till min bror. |
| | | <span lang="de">Ich lerne für **die Prüfung**.</span> | Jag pluggar inför provet. |
| <span lang="de">**gegen**</span> | mot (fysiskt/tid/åsikt) | <span lang="de">Er fährt gegen **einen Baum**.</span> | Han kör in i ett träd. |
| | | <span lang="de">Wir treffen uns gegen **acht Uhr**.</span> | Vi ses vid åttatiden. |
| <span lang="de">**ohne**</span> | utan, saknad av | <span lang="de">Ohne **dich** gehe ich nicht.</span> | Utan dig går jag inte. |
| | | <span lang="de">Kaffee ohne **Zucker**, bitte.</span> | Kaffe utan socker, tack. |
| <span lang="de">**um**</span> | runt, omkring, klockslag | <span lang="de">Die Kinder laufen um **das Haus**.</span> | Barnen springer runt huset. |
| | | <span lang="de">Der Zug fährt um **zehn Uhr**.</span> | Tåget går klockan tio. |

## 2. Specialfallet: BIS

Prepositionen **bis** (*tills, fram till*) styr också ackusativ, men den står sällan ensam framför en artikel:
* Ensam framför städer, datum och siffror:  
  <span lang="de">Der Zug fährt bis **Berlin**.</span>  
  <span lang="de">Bis **morgen**!</span> (Vi ses imorgon!)  
  <span lang="de">Von Montag bis **Freitag**.</span>
* Framför en artikel kombineras den nästan alltid med en annan preposition som då avgör kasuset:
  * <span lang="de">bis **zu dem** Bahnhof</span> -> <span lang="de">bis **zum** Bahnhof</span> (zu styr dativ!).
  * <span lang="de">bis **an das** Meer</span> -> <span lang="de">bis **ans** Meer</span> (an + ackusativ).

---

## 3. Vanliga sammandragningar

I vardagligt tal smälter ackusativprepositioner ofta ihop med neutral artikel **das**:
* <span lang="de">für + das</span> -> <span lang="de">**fürs**</span>: <span lang="de">Das ist fürs Kind.</span>
* <span lang="de">um + das</span> -> <span lang="de">**ums**</span>: <span lang="de">Wir gehen ums Eck.</span>
* <span lang="de">durch + das</span> -> <span lang="de">**durchs**</span>: <span lang="de">Der Hund rennt durchs Zimmer.</span>

## 10 autentiska exempel

1. <span lang="de">Wir spazieren durch **den dichten Wald**.</span>  
   *(durch styr ackusativ maskulinum: den dichten Wald.)*
2. <span lang="de">Dieses Geschenk habe ich für **meine liebe Mutter** gekauft.</span>  
   *(für styr ackusativ femininum: meine liebe Mutter.)*
3. <span lang="de">Er hat ohne **seinen warmen Mantel** das Haus verlassen.</span>  
   *(ohne styr ackusativ maskulinum: seinen warmen Mantel.)*
4. <span lang="de">Um **wie viel Uhr** beginnt die Vorlesung?</span>  
   *(um för klockslag styr ackusativ.)*
5. <span lang="de">Sie protestieren gegen **das neue Gesetz**.</span>  
   *(gegen styr ackusativ neutrum: das neue Gesetz.)*
6. <span lang="de">Ohne **eure Hilfe** hätten wir das nie geschafft.</span>  
   *(ohne styr ackusativ: eure Hilfe.)*
7. <span lang="de">Er ging durch **die offene Tür** ins Wohnzimmer.</span>  
   *(durch styr ackusativ femininum: die offene Tür.)*
8. <span lang="de">Hast du etwas gegen **meinen Plan**?</span>  
   *(gegen styr ackusativ maskulinum: meinen Plan.)*
9. <span lang="de">Ich habe Blumen für **dich** mitgebracht.</span>  
   *(für med personligt pronomen i ackusativ: dich.)*
10. <span lang="de">Die Erde dreht sich um **die Sonne**.</span>  
    *(um i betydelsen runt/omkring: die Sonne.)*
