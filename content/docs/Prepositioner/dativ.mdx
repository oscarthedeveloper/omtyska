## Kärnan på en halv minut

Dessa prepositioner styr **undantagslöst dativ**:

```
   AUS · BEI · MIT · NACH · SEIT · VON · ZU  (samt AUßER, GEGENÜBER)
```

Klassisk minnesramsa:  
*Aus, bei, mit, nach, seit, von, zu — fährst du stets im Dativ, du!*

Efter dessa prepositioner heter artiklarna **alltid**:
* Maskulinum: <span lang="de">**dem** / **einem**</span>
* Femininum: <span lang="de">**der** / **einer**</span>
* Neutrum: <span lang="de">**dem** / **einem**</span>
* Plural: <span lang="de">**den (+n)** / **keinen (+n)**</span>

## 1. De viktigaste prepositionerna i detalj

| Preposition | Grundbetydelse | Exempel på tyska | Betydelse |
| :--- | :--- | :--- | :--- |
| <span lang="de">**aus**</span> | ut ur, från, gjord av | <span lang="de">Ich komme aus **der Schweiz**.</span> | Jag kommer från Schweiz. |
| | | <span lang="de">Er trinkt aus **einem Glas**.</span> | Han dricker ur ett glas. |
| <span lang="de">**bei**</span> | hos, vid, i närheten | <span lang="de">Ich wohne bei **meinen Eltern**.</span> | Jag bor hos mina föräldrar. |
| | | <span lang="de">Er arbeitet bei **Siemens**.</span> | Han jobbar på Siemens. |
| <span lang="de">**mit**</span> | med, tillsammans med | <span lang="de">Ich fahre mit **dem Bus**.</span> | Jag åker med bussen. |
| | | <span lang="de">Kommst du mit **mir**?</span> | Kommer du med mig? |
| <span lang="de">**nach**</span> | till (städer/länder), efter | <span lang="de">Wir fahren nach **Berlin**.</span> | Vi åker till Berlin. |
| | | <span lang="de">Nach **der Arbeit** gehe ich joggen.</span> | Efter jobbet joggar jag. |
| <span lang="de">**seit**</span> | sedan, under (pågående) | <span lang="de">Er wohnt seit **einem Jahr** hier.</span> | Han har bott här i ett år. |
| <span lang="de">**von**</span> | från, av (ägande) | <span lang="de">Das ist ein Geschenk von **meinem Bruder**.</span> | Det är en present från min bror. |
| <span lang="de">**zu**</span> | till (personer/institutioner) | <span lang="de">Ich gehe zu **meiner Oma**.</span> | Jag går till min mormor. |
| | | <span lang="de">Gehen wir zu **Fuß**?</span> | Går vi till fots? |
| <span lang="de">**gegenüber**</span> | mittemot | <span lang="de">Das Hotel liegt gegenüber **dem Bahnhof**.</span> | Hotellet ligger mittemot stationen. |

## 2. Den stora fällan: "Rörelse = Ackusativ?" NEJ!

En av de mest spridda missuppfattningarna i tysk grammatik är att *all* rörelse kräver ackusativ.

* Ackusativ vid rörelse gäller **ENDAST för växelprepositionerna** (*in, an, auf, neben, hinter, über, unter, vor, zwischen*).
* Prepositionerna **nach** och **zu** anger båda rörelse mot ett mål, men de är **rena dativprepositioner** och styr ALLTID **dativ**:
  * <span lang="de">Ich gehe zu **dem Arzt**</span> -> <span lang="de">Ich gehe **zum Arzt** (Dativ!).</span>
  * <span lang="de">Ich fahre nach **Hause** / zu **Hause**.</span>

---

## 3. Obligatoriska sammandragningar

I talad och skriven tyska smälter preposition + artikel oftast samman:

* <span lang="de">bei + dem</span> -> <span lang="de">**beim**</span>: <span lang="de">beim Arzt</span>, <span lang="de">beim Essen</span>
* <span lang="de">von + dem</span> -> <span lang="de">**vom**</span>: <span lang="de">vom Bahnhof</span>, <span lang="de">vom Tisch</span>
* <span lang="de">zu + dem</span> -> <span lang="de">**zum**</span>: <span lang="de">zum Bahnhof</span>, <span lang="de">zum Supermarkt</span>
* <span lang="de">zu + der</span> -> <span lang="de">**zur**</span>: <span lang="de">zur Schule</span>, <span lang="de">zur Arbeit</span>

---

## 10 autentiska exempel

1. <span lang="de">Ich fahre jeden Morgen mit **der U-Bahn** zur Arbeit.</span>  
   *(mit styr dativ femininum: der U-Bahn; zur = zu + der Arbeit.)*
2. <span lang="de">Er wohnt seit **drei Monaten** in Wien.</span>  
   *(seit styr dativ plural med ändelse -n: drei Monaten.)*
3. <span lang="de">Nach **dem Abendessen** machen wir einen Spaziergang.</span>  
   *(nach styr dativ neutrum: dem Abendessen.)*
4. <span lang="de">Wir haben das Auto von **unserem Nachbarn** geliehen.</span>  
   *(von styr dativ maskulinum: unserem Nachbarn.)*
5. <span lang="de">Gestern war ich beim **Zahnarzt**.</span>  
   *(beim = bei + dem Zahnarzt i dativ.)*
6. <span lang="de">Kommen Sie bitte aus **dem kalten Wasser** heraus!</span>  
   *(aus styr dativ neutrum: dem kalten Wasser.)*
7. <span lang="de">Das Café liegt direkt gegenüber **der alten Kirche**.</span>  
   *(gegenüber styr dativ femininum: der alten Kirche.)*
8. <span lang="de">Alle Schüler außer **ihm** haben die Prüfung bestanden.</span>  
   *(außer styr dativ maskulinum: ihm.)*
9. <span lang="de">Ich muss heute noch zur **Bank** gehen.</span>  
   *(zur = zu + der Bank i dativ femininum.)*
10. <span lang="de">Er trank einen Schluck Wasser aus **seiner Flasche**.</span>  
    *(aus styr dativ femininum: seiner Flasche.)*
