## Kärnan på en halv minut

Ett verb med fast preposition är en fast enhet som alltid måste läras in som **Verb + Preposition + Kasus**:

```
Verb + Preposition       Kasus        Svensk betydelse         Exempel
------------------------------------------------------------------------------------------------------
warten auf               Ackusativ    vänta på                 Ich warte **auf den Bus**.
denken an                Ackusativ    tänka på                 Denkst du **an unsere Verabredung**?
sich freuen auf          Ackusativ    glädja sig åt (framtid)  Wir freuen uns **auf das Wochenende**.
sich freuen über         Ackusativ    vara glad över           Er freute sich **über das Geschenk**.
bitten um                Ackusativ    be om                    Darf ich **um Hilfe** bitten?
sich interessieren für   Ackusativ    intressera sig för       Sie interessiert sich **für Kunst**.
------------------------------------------------------------------------------------------------------
teilnehmen an            Dativ        delta i                  Er nimmt **am Seminar** teil.
träumen von              Dativ        drömma om                Ich träume **von einer langen Reise**.
abhängen von             Dativ        bero på                  Das hängt **vom Wetter** ab.
warnen vor               Dativ        varna för                Die Polizei warnt **vor Taschendieben**.
```

---

## 1. Verbgrupp 1: Fasta prepositioner med ackusativ

Dessa verb styr ofta en handling eller en tanke som riktas mot ett mål:

* **auf + ackusativ:**
  * <span lang="de">warten auf</span> *(vänta på)*: <span lang="de">Ich warte auf dich.</span>
  * <span lang="de">hoffen auf</span> *(hoppas på)*: <span lang="de">Wir hoffen auf besseres Wetter.</span>
  * <span lang="de">achten auf</span> *(akta sig för / lägga märke till)*: <span lang="de">Achte auf den Verkehr!</span>
  * <span lang="de">verzichten auf</span> *(avstå från)*: <span lang="de">Er verzichtet auf das Dessert.</span>
* **an + ackusativ:**
  * <span lang="de">denken an</span> *(tänka på)*: <span lang="de">Ich denke oft an meine Heimat.</span>
  * <span lang="de">glauben an</span> *(tro på)*: <span lang="de">Glaubst du an Wunder?</span>
  * <span lang="de">sich erinnern an</span> *(minnas / komma ihåg)*: <span lang="de">Erinnert ihr euch an mich?</span>
* **um + ackusativ:**
  * <span lang="de">bitten um</span> *(be om)*: <span lang="de">Ich bitte um Verzeihung.</span>
  * <span lang="de">es geht um</span> *(det handlar om)*: <span lang="de">Worum geht es in dem Film?</span>
  * <span lang="de">sich bewerben um</span> *(söka [en tjänst])*: <span lang="de">Sie bewirbt sich um die Stelle.</span>

---

## 2. Verbgrupp 2: Fasta prepositioner med dativ

Dessa verb styr ofta en koppling, källa eller orsak:

* **von + dativ:**
  * <span lang="de">träumen von</span> *(drömma om)*: <span lang="de">Er träumt von einem eigenen Haus.</span>
  * <span lang="de">abhängen von</span> *(bero på)*: <span lang="de">Alles hängt vom Zufall ab.</span>
  * <span lang="de">erzählen von</span> *(berätta om)*: <span lang="de">Erzähl mir von deiner Reise!</span>
* **an + dativ:**
  * <span lang="de">teilnehmen an</span> *(delta i)*: <span lang="de">Wer nimmt an der Besprechung teil?</span>
  * <span lang="de">zweifeln an</span> *(tvivla på)*: <span lang="de">Ich zweifle an seinen Worten.</span>
  * <span lang="de">leiden an</span> *(lida av en specifik sjukdom)*: <span lang="de">Er leidet an Diabetes.</span>
* **vor + dativ:**
  * <span lang="de">Angst haben vor</span> *(vara rädd för)*: <span lang="de">Hast du Angst vor Spinnen?</span>
  * <span lang="de">warnen vor</span> *(varna för)*: <span lang="de">Man warnte uns vor dem Sturm.</span>
  * <span lang="de">schützen vor</span> *(skydda mot)*: <span lang="de">Die Creme schützt vor der Sonne.</span>

---

## 3. Två berömda skillnader

### 1. sich freuen auf kontra sich freuen über
* **sich freuen auf (+ ack)** = glädjas åt något som **ligger i framtiden** (förväntan):  
  <span lang="de">Ich freue mich **auf die Ferien** nächste Woche.</span>
* **sich freuen über (+ ack)** = vara glad över något som **redan hänt eller finns i nuet**:  
  <span lang="de">Ich habe mich sehr **über deinen Brief** gefreut.</span>

### 2. leiden an kontra leiden unter
* **leiden an (+ dat)** = lida av en **medicinsk diagnos eller sjukdom**:  
  <span lang="de">Sie leidet **an einer schweren Grippe**.</span>
* **leiden unter (+ dat)** = plågas av en **yttre eller psykisk omständighet**:  
  <span lang="de">Viele Menschen leiden **unter dem Lärm** der Großstadt.</span>

## 4. Frågor och koppling till pronominaladverb

När du frågar eller svarar gäller den etablerade person/sak-regeln (se [R11](file:///Users/oscarpagerup/Desktop/Git%20Repo/Om-Tyska/content/docs/Pronomen/dar-och-wor.mdx)):

```
Verb              Fråga om SAK              Fråga om PERSON
---------------------------------------------------------------------------------
warten auf        **Worauf** wartest du?    **Auf wen** wartest du?
denken an         **Woran** denkst du?      **An wen** denkst du?
sprechen über     **Worüber** sprecht ihr?  **Über wen** sprecht ihr?
träumen von       **Wovon** träumst du?     **Von wem** träumst du?
```

---

## Svenska interferenser och fallgropar

1. **"Drömma om"**: Översätt aldrig svenskans "om" med *über*. Det heter alltid <span lang="de">träumen von + dativ</span>.
2. **"Tänka på"**: Översätt inte med *auf*. Det heter <span lang="de">denken an + ackusativ</span>.
3. **"Delta i"**: Översätt inte med *in*. Det heter <span lang="de">teilnehmen an + dativ</span>.

---

## 10 autentiska exempel

1. <span lang="de">Wir **warten schon seit zwanzig Minuten auf das Taxi**.</span>  
   *(warten auf + ackusativ: das Taxi.)*
2. <span lang="de">Ich habe den ganzen Abend **an dich gedacht**.</span>  
   *(denken an + ackusativ vid person: an dich.)*
3. <span lang="de">Die Kinder **freuen sich schon riesig auf Weihnachten**.</span>  
   *(sich freuen auf för framtida högtid.)*
4. <span lang="de">Vielen Dank, ich habe mich sehr **über die Blumen gefreut**!</span>  
   *(sich freuen über för mottagen present.)*
5. <span lang="de">Möchtest du auch **an dem Ausflug teilnehmen**?</span>  
   *(teilnehmen an + dativ: dem Ausflug.)*
6. <span lang="de">Darf ich Sie **um einen kurzen Moment Geduld bitten**?</span>  
   *(bitten um + ackusativ.)*
7. <span lang="de">Er **träumt schon lange von einer Reise** um die Welt.</span>  
   *(träumen von + dativ: einer Reise.)*
8. <span lang="de">Die Entscheidung **hängt von vielen verschiedenen Faktoren ab**.</span>  
   *(abhängen von + dativ plural: Faktoren.)*
9. <span lang="de">Der Wetterdienst **warnt vor schweren Gewittern** am Abend.</span>  
   *(warnen vor + dativ plural: Gewittern.)*
10. <span lang="de">Sie hat überhaupt keine **Angst vor Prüfungen**.</span>  
    *(Angst vor + dativ plural.)*
