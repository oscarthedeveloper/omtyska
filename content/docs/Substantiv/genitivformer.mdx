## Kärnan på en halv minut

I tyskan är det **endast maskulina och neutrala substantiv i singular** som får en kasusändelse i genitiv:

```
GENUS              ARTIKEL          SUBSTANTIVÄNDELSE     EXEMPEL
-------------------------------------------------------------------------------------
Maskulinum:        des / eines      -(e)s                 des Mann-ES, des Vater-S
Neutrum:           des / eines      -(e)s                 des Kind-ES, des Auto-S
Femininum:         der / einer      INGEN ÄNDELSE!        der Frau, der Mutter
Plural:            der / meiner     INGEN ÄNDELSE!        der Kinder, der Freunde
```

Varning för svenskar: Skriv aldrig *"der Frau's"* eller *"der Mütters"*! Feminina substantiv och pluralformer har absolut ingen genitivändelse på själva substantivet.

---

## 1. När ska man välja "-es" och när "-s"?

Valet mellan **-es** och **-s** på maskulina och neutrala ord styrs av fonetiska regler:

### A. Obligatoriskt "-es" (krävs för uttalet):
Efter alla ord som slutar på ett **s-ljud** (*-s, -ss, -ß, -z, -tz, -x*):
* <span lang="de">das Glas</span> -> <span lang="de">des Glas**es**</span>
* <span lang="de">der Fluss</span> -> <span lang="de">des Fluss**es**</span>
* <span lang="de">der Platz</span> -> <span lang="de">des Platz**es**</span>
* <span lang="de">das Gesetz</span> -> <span lang="de">des Gesetz**es**</span>
* <span lang="de">der Reflex</span> -> <span lang="de">des Reflex**es**</span>

### B. Stark preferens för "-es":
Vid de flesta **enstaviga basord** (särskilt med konsonantkluster i slutet):
* <span lang="de">das Kind</span> -> <span lang="de">des Kind**es**</span> (des Kinds är ovanligare)
* <span lang="de">der Mann</span> -> <span lang="de">des Mann**es**</span>
* <span lang="de">das Bild</span> -> <span lang="de">des Bild**es**</span>
* <span lang="de">das Jahr</span> -> <span lang="de">des Jahr**es**</span> (eller des Jahrs)

### C. Obligatoriskt "-s" (inte -es):
Vid **flerstaviga ord som slutar på obetonat *-el, -en, -er*** samt ord som slutar på **vokal**:
* <span lang="de">der Lehrer</span> -> <span lang="de">des Lehrer**s**</span> *(aldrig des Lehreres)*
* <span lang="de">der Vater</span> -> <span lang="de">des Vater**s**</span>
* <span lang="de">der Wagen</span> -> <span lang="de">des Wagen**s**</span>
* <span lang="de">das Auto</span> -> <span lang="de">des Auto**s**</span>
* <span lang="de">das Radio</span> -> <span lang="de">des Radio**s**</span>

## 2. Egennamn: Peter, Anna och Goethe

När du använder personnamn och geografiska namn i genitiv placeras namnet **framför** det ägda föremålet:

* <span lang="de">**Peters** neues Auto</span> *(Peters nya bil – INGEN apostrof!)*
* <span lang="de">**Annas** Wohnung</span> *(Annas lägenhet)*
* <span lang="de">**Schillers** Dramen</span> *(Schillers dramer)*
* <span lang="de">**Schwedens** Wirtschaft</span> *(Sveriges ekonomi)*

```
OBS: "Deppenapostroph" (Idiotapostrof)
  I tyskan sätts ALDRIG apostrof vid vanliga genitiv-s:
    "Peter's Auto"  --> FEL! (engelskt stavsätt)
    "Peters Auto"   --> RÄTT tysk stavning!
```

### Namn som slutar på s-ljud:
Om namnet redan slutar på ett s-ljud (*-s, -ss, -ß, -z, -x, -ce*) läggs en **ren apostrof** till i slutet utan extra s:
* <span lang="de">**Max’** Fahrrad</span> *(Max cykel)*
* <span lang="de">**Lukas’** Schwester</span> *(Lukas syster)*
* <span lang="de">**Johannes’** Evangelium</span>
* <span lang="de">**Marx’** Theorien</span> *(Marx teorier)*

---

## 3. "Von + Dativ" som talspråkligt alternativ

I modernt talspråk ersätts genitivattributet mycket ofta med **von + Dativ**:
* Skrift (Genitiv): <span lang="de">das Dach **des Hauses**</span>
* Tal (von + Dativ): <span lang="de">das Dach **von dem Haus**</span>

Det finns dock sammanhang där "von" är **obligatoriskt** även i skrift:
1. När substantivet i plural saknar artikel eller adjektiv som kan visa genitiven:  
   <span lang="de">der Import **von Waren**</span> *(inte der Import Waren)*
2. Efter pronomen och räkneord:  
   <span lang="de">einer **von uns**</span> *(en av oss)*, <span lang="de">drei **von den Studenten**</span>

## 10 autentiska exempel

1. <span lang="de">Der Zustand **des alten Hauses** verschlechterte sich rapide.</span>  
   *(enstavigt neutrum: des Hauses med -es.)*
2. <span lang="de">Das Büro **unseres Abteilungsleiters** befindet sich im dritten Stock.</span>  
   *(flerstavigt ord på -er: des Leiters med enkelt -s.)*
3. <span lang="de">**Mozarts** Musik wird auf der ganzen Welt geliebt.</span>  
   *(egennamn i genitiv utan apostrof.)*
4. <span lang="de">**Klaus’** neue Brille steht ihm hervorragend.</span>  
   *(namn på s-ljud: Klaus’ med apostrof.)*
5. <span lang="de">Die Beschlüsse **des Kongresses** wurden einstimmig gefasst.</span>  
   *(ord på s-ljud: des Kongresses med -es.)*
6. <span lang="de">Das Lächeln **der kleinen Tochter** bezauberte alle Gäste.</span>  
   *(feminin genitiv: der Tochter utan ändelse på substantivet!)*
7. <span lang="de">Die Zukunft **Europas** liegt in den Händen der Jugend.</span>  
   *(geografiskt namn utan artikel: Europas.)*
8. <span lang="de">Trotz **des schlechten Wetters** fand das Open-Air-Konzert statt.</span>  
   *(genitiv neutrum: des Wetters.)*
9. <span lang="de">Ist das das Fahrrad **von deinem Bruder**?</span>  
   *(ledigt talspråk med von + dativ.)*
10. <span lang="de">Die Unterstützung **vieler Bürger** war entscheidend für den Erfolg.</span>  
    *(genitiv plural: vieler Bürger.)*
