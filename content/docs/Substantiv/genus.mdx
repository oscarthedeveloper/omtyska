## Kärnan på en halv minut

I tyskan har varje substantiv ett fast grammatiskt genus som syns på den bestämda artikeln i **nominativ**:

* **Maskulinum (m)**: <span lang="de">**der** Mann</span>, <span lang="de">**der** Tisch</span>, <span lang="de">**der** Tag</span>
* **Femininum (f)**: <span lang="de">**die** Frau</span>, <span lang="de">**die** Tür</span>, <span lang="de">**die** Nacht</span>
* **Neutrum (n)**: <span lang="de">**das** Kind</span>, <span lang="de">**das** Buch</span>, <span lang="de">**das** Haus</span>

Det finns två gyllene principer för att förstå genuset:
1. **Morfologiska avledningssuffix styr genuset regelbundet**: Har ordet ett produktivt suffix som *-ung, -heit, -keit* eller diminutivet *-chen* är genuset grammatiskt bestämt oavsett ordets betydelse.
2. **Grammatiskt genus är inte samma sak som biologiskt kön**: Det handlar om ordets form och morfologi, inte om objektets natur!

## 1. De säkra femininändelserna (Alltid DIE!)

Om ett substantiv slutar på någon av följande ändelser är det **nästan utan undantag femininum**:

| Ändelse | Regel | Exempel | Betydelse |
| :--- | :--- | :--- | :--- |
| **-ung** | 100 % femininum | <span lang="de">**die Zeitung**</span>, <span lang="de">**die Wohnung**</span> | tidning, lägenhet |
| **-heit** | 100 % femininum | <span lang="de">**die Freiheit**</span>, <span lang="de">**die Krankheit**</span> | frihet, sjukdom |
| **-keit** | 100 % femininum | <span lang="de">**die Möglichkeit**</span>, <span lang="de">**die Schnelligkeit**</span> | möjlighet, snabbhet |
| **-schaft** | 100 % femininum | <span lang="de">**die Freundschaft**</span>, <span lang="de">**die Mannschaft**</span> | vänskap, lag |
| **-tion** | 100 % femininum (lånord) | <span lang="de">**die Station**</span>, <span lang="de">**die Situation**</span> | station, situation |
| **-tät** | 100 % femininum (lånord) | <span lang="de">**die Universität**</span>, <span lang="de">**die Qualität**</span> | universitet, kvalitet |
| **-ie** (betonat) | Franska/grekiska lånord (femininum, jfr lånordet *das Genie*) | <span lang="de">**die Energie**</span>, <span lang="de">**die Familie**</span> | energi, familj |
| **-e** | Ca 90 % femininum (tvåstavingar) | <span lang="de">**die Lampe**</span>, <span lang="de">**die Straße**</span>, <span lang="de">**die Tasche**</span> | lampa, gata, väska |

## 2. De säkra neutrumändelserna (Alltid DAS!)

| Ändelse / Typ | Regel | Exempel | Betydelse |
| :--- | :--- | :--- | :--- |
| **-chen / -lein** | Förminskningsord (diminutiv) | <span lang="de">**das Mädchen**</span>, <span lang="de">**das Brötchen**</span> | flicka, småfranska |
| **-ment** | Lånord | <span lang="de">**das Dokument**</span>, <span lang="de">**das Instrument**</span> | dokument, instrument |
| **-um** | Latinska lånord | <span lang="de">**das Museum**</span>, <span lang="de">**das Zentrum**</span> | museum, centrum |
| **Infinitiver** | Substantiverade verb | <span lang="de">**das Essen**</span>, <span lang="de">**das Leben**</span> | maten, livet |
| **Ge-...-e** | Kollektivbildningar | <span lang="de">**das Gebäude**</span>, <span lang="de">**das Gebirge**</span> | byggnad, bergskedja |

<div className="callout callout-info">
  <p className="callout-title">💡 Varför heter det "das Mädchen"?</p>
  <p>
    En flicka är förstås biologiskt en person av kvinnligt kön. Men i ordet <em>Mädchen</em> finns det produktiva diminutivsuffixet <strong>-chen</strong> (förminskningsform av det äldre ordet <em>Magd</em>, mö/flicka).
    I tysk grammatik vinner <strong>diminutivsuffixet över biologin</strong>: avledningar med diminutiven <em>-chen</em> och <em>-lein</em> är alltid grammatiskt neutrum!
    (Obs: Förväxla inte diminutivsuffixet med ord som råkar sluta på bokstäverna <em>-chen</em> som del av stammen, t.ex. det maskulina ordet <em>der Kuchen</em> [kakan] eller <em>der Knochen</em> [benet].)
  </p>
</div>

## 3. De säkra maskulinändelserna (Alltid DER!)

| Ändelse / Betydelse | Regel | Exempel | Betydelse |
| :--- | :--- | :--- | :--- |
| **-ismus** | Ismer och åskådningar | <span lang="de">**der Optimismus**</span>, <span lang="de">**der Tourismus**</span> | optimism, turism |
| **-or** | Lånord (aktörer, apparater) | <span lang="de">**der Motor**</span>, <span lang="de">**der Professor**</span> | motor, professor |
| **-ling** | Personer / små ting | <span lang="de">**der Frühling**</span>, <span lang="de">**der Schmetterling**</span> | vår, fjäril |
| **-er** | Manliga yrkesutövare och verktyg | <span lang="de">**der Lehrer**</span>, <span lang="de">**der Computer**</span> | lärare, dator |
| **Dagar, månader, årstider** | Semantisk grupp (alltid mask.) | <span lang="de">**der Montag**</span>, <span lang="de">**der Juli**</span>, <span lang="de">**der Sommer**</span> | måndag, juli, sommar |
| **Väderfenomen** | Vind, regn, snö | <span lang="de">**der Regen**</span>, <span lang="de">**der Wind**</span>, <span lang="de">**der Schnee**</span> | regn, vind, snö |

## 10 autentiska exempel

1. <span lang="de">**Die Wohnung** ist sehr hell und modern.</span>  
   *(-ung är alltid femininum: die Wohnung.)*
2. <span lang="de">**Das Mädchen** liest ein spannendes Buch.</span>  
   *(-chen ger alltid neutrum: das Mädchen.)*
3. <span lang="de">**Der Sommer** in Schweden ist wunderschön.</span>  
   *(Årstider är alltid maskulinum: der Sommer.)*
4. <span lang="de">Wir besuchen morgen **das Museum** für Kunst.</span>  
   *(-um är neutrum: das Museum.)*
5. <span lang="de">**Die Freiheit** der Presse ist ein hohes Gut.</span>  
   *(-heit är alltid femininum: die Freiheit.)*
6. <span lang="de">Er arbeitet als **der neue Professor** an der Universität.</span>  
   *(-or är maskulinum; -tät är femininum.)*
7. <span lang="de">Möchtest du noch ein kleines **Brötchen**?</span>  
   *(-chen ger neutrum: das Brötchen.)*
8. <span lang="de">**Die Qualität** dieser Produkte ist hervorragend.</span>  
   *(-tät ger alltid femininum.)*
9. <span lang="de">**Der Regen** hat den ganzen Tag nicht aufgehört.</span>  
   *(Väderord är maskulinum: der Regen.)*
10. <span lang="de">**Das Leben** in einer Großstadt ist oft hektisch.</span>  
    *(Substantiverad infinitiv är alltid neutrum: das Leben.)*
