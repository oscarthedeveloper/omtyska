## Kärnan på en halv minut

Ett tyskt sammansatt ord (**Kompositum**) består av minst två delar:
1. **Bestimmungswort** (Första ledet): Beskriver *vilken typ* av sak det handlar om. Tar huvudbetoningen!
2. **Grundwort** (Sista ledet): Talar om *vad* saken är. **Bestämmer genus, artikel och böjning!**

```
Bestimmungswort (beskriver)   +   Grundwort (huvudord)   =   Kompositum
-------------------------------------------------------------------------------------
das Auto (bil)               +   DIE BAHN (bana/tåg)    =   DIE Autobahn
die Kinder (barn)            +   DAS ZIMMER (rum)       =   DAS Kinderzimmer
der Apfel (äpple)            +   DER KUCHEN (kaka)      =   DER Apfelkuchen
```

Oavsett om det första ordet är maskulint, feminint, ett verb eller ett adjektiv är det **alltid sista ordets artikel** som gäller:
* <span lang="de">rot</span> (adjektiv) + <span lang="de">der Wein</span> = <span lang="de">**der** Rotwein</span>
* <span lang="de">schlafen</span> (verb) + <span lang="de">das Zimmer</span> = <span lang="de">**das** Schlafzimmer</span>

## 1. Fogelement (Fugenlaute): När orden fogas samman

Ofta sätts orden ihop direkt (<span lang="de">das Haus + die Tür = die Haustür</span>). Men mycket ofta skjuts ett litet bindeelement in mellan orden:

### A. Fugen-s (det vanligaste fogelementet)
Uppträder särskilt när förledet slutar på feminina suffix som *-ung, -heit, -keit, -schaft, -tät, -tion* samt efter vissa neutrala/maskulina ord:
* <span lang="de">die Hoffnung</span> + s + <span lang="de">los</span> = <span lang="de">hoffnung**s**los</span>
* <span lang="de">die Geburt</span> + s + <span lang="de">der Tag</span> = <span lang="de">der Geburtstag</span> *(födelsedag)*
* <span lang="de">die Arbeit</span> + s + <span lang="de">das Zimmer</span> = <span lang="de">das Arbeitszimmer</span> *(arbetsrum)*
* <span lang="de">die Universität</span> + s + <span lang="de">die Klinik</span> = <span lang="de">die Universitätsklinik</span>

### B. Fugen-(e)n
Uppträder ofta när förledet är ett feminint ord som bildar plural på *-en*, eller ett svagt maskulinum:
* <span lang="de">die Küche</span> + n + <span lang="de">der Schrank</span> = <span lang="de">der Küchenschrank</span> *(köksskåp)*
* <span lang="de">die Birne</span> + n + <span lang="de">der Baum</span> = <span lang="de">der Birnenbaum</span> *(päronträd)*
* <span lang="de">der Student</span> + en + <span lang="de">das Wohnheim</span> = <span lang="de">das Studentenwohnheim</span>

### C. Fugen-er
När förledet är ett substantiv som bildar plural med *-er*:
* <span lang="de">das Kind</span> + er + <span lang="de">der Garten</span> = <span lang="de">der Kindergarten</span>
* <span lang="de">das Bild</span> + er + <span lang="de">das Buch</span> = <span lang="de">das Bilderbuch</span> *(bilderbok)*

## 2. Betoning: Alltid på första ledet!

I alla tyska sammansättningar ligger den primära betoningen på **det första ledet (Bestimmungswort)**:

* <span lang="de">die **Au**tobahn</span> *(inte autobahn)*
* <span lang="de">der **Kaf**feebecher</span>
* <span lang="de">die **Bahn**hofstraße</span>

Detta hjälper dig att skilja en sammansättning från två separata ord:
* <span lang="de">ein **Rot**wein</span> *(rött vin som vintyp)*
* <span lang="de">ein roter **Wein**</span> *(ett vin som råkar vara rött)*

---

## 3. Hur du dekonstruerar långa monsterord

När du möter ett långt sammansatt ord som du inte känner igen, följ denna enkla trestegsmetod:
1. **Dela ordet från höger till vänster:** Hitta sista ordet först. Det är kärnbegreppet!
2. **Identifiera fogelement:** Skala bort eventuella *-s-* eller *-en-*.
3. **Översätt förledet:** Förledet talar om vad för sorts kärnord det rör sig om.

Exempel: <span lang="de">Reisekrankenversicherung</span>
* *Versicherung* (försäkring, die)
* + s + *kranken* (sjuk)
* + *Reise* (resa)
* = Resesjukförsäkring! Genus: **die** (efter die Versicherung).

## 10 autentiska exempel

1. <span lang="de">Ich muss mir noch eine neue **Zahnbürste** kaufen.</span>  
   *(die Zähne + die Bürste = die Zahnbürste.)*
2. <span lang="de">Wir treffen uns heute Nachmittag vor dem **Hauptbahnhof**.</span>  
   *(die Haupt- + der Bahnhof = der Hauptbahnhof.)*
3. <span lang="de">Der **Apfelsaft** steht gekühlt im Kühlschrank.</span>  
   *(der Apfel + der Saft = der Apfelsaft.)*
4. <span lang="de">Hast du deinen **Reisepass** eingepackt?</span>  
   *(die Reise + der Pass = der Reisepass.)*
5. <span lang="de">Das **Wörterbuch** liegt auf meinem Schreibtisch.</span>  
   *(die Wörter + das Buch = das Wörterbuch.)*
6. <span lang="de">Sie feierten bis spät in die Nacht den **Geburtstag** ihrer Tochter.</span>  
   *(die Geburt + s + der Tag = der Geburtstag.)*
7. <span lang="de">In der Großstadt gibt es viele moderne **Wohnhochhäuser**.</span>  
   *(wohnen + hoch + das Haus -> Häuser.)*
8. <span lang="de">Das neue **Umweltschutzgesetz** tritt nächsten Monat in Kraft.</span>  
   *(die Umwelt + der Schutz + s + das Gesetz = das Gesetz.)*
9. <span lang="de">Er hat sich eine schwere **Grippeimpfung** geben lassen.</span>  
   *(die Grippe + die Impfung = die Impfung.)*
10. <span lang="de">Auf dem **Kinderspielplatz** spielten viele Kinder im Sand.</span>  
    *(die Kinder + das Spiel + der Platz = der Spielplatz.)*
