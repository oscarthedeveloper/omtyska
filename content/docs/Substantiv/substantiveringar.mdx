## Kärnan på en halv minut

I tyskan finns tre huvudtyper av substantiveringar:

```
1. SUBSTANTIVERADE VERB (Infinitiver)  ──> ALLTID DAS!
   lesen (läsa)     ──> das Lesen     (läsandet / läsning)
   schwimmen        ──> das Schwimmen (simningen / att simma)
   essen            ──> das Essen     (maten / ätandet)

2. SUBSTANTIVERADE ADJEKTIV (Personer) ──> BÖJS SOM ADJEKTIV!
   Maskulinum:  der Deutsche  / ein Deutscher   (en tysk man)
   Femininum:   die Deutsche  / eine Deutsche   (en tysk kvinna)
   Plural:      die Deutschen / viele Deutsche  (tyskar)

3. ABSTRAKTA SUBSTANTIVERINGAR (Efter etwas, nichts, viel, wenig)
   etwas Neu-ES   (något nytt)       nichts Gut-ES   (inget bra)
   viel Schönes   (mycket vackert)   alles Gut-E     (allt gott)
```

Gemensamt för alla tre: De skrivs **alltid med stor begynnelsebokstav**!

---

## 1. Substantiverade infinitiver (Alltid Neutrum)

Att göra ett verb till ett substantiv är extremt enkelt i tyskan:
* Ta verbets grundform (infinitiv).
* Sätt artikeln **das** framför.
* Skriv verbet med **stor begynnelsebokstav**!

| Infinitiv | Substantiverad form | Betydelse |
| :--- | :--- | :--- |
| **leben** *(leva)* | <span lang="de">**das Leben**</span> | livet |
| **sprechen** *(tala)* | <span lang="de">**das Sprechen**</span> | talandet |
| **arbeiten** *(arbeta)* | <span lang="de">**das Arbeiten**</span> | arbetet / arbetandet |
| **rauchen** *(röka)* | <span lang="de">**das Rauchen**</span> | rökningen |

Exempel i meningar:
* <span lang="de">**Das Rauchen** ist hier streng verboten.</span> *(Rökning är strikt förbjuden här.)*
* <span lang="de">Beim **Lesen** trinke ich gern Tee.</span> *(Vid läsning dricker jag gärna te.)*

## 2. Personbeteckningar: Ord som böjs som adjektiv

Många vanliga tyska ord för personer är ursprungligen adjektiv eller particip. De fungerar som substantiv men **behåller fullständig adjektivböjning**:

* **der/ein Deutsche** *(tysk)*, **der/ein Bekannte** *(bekant)*, **der/ein Verwandte** *(släkting)*, **der/ein Angestellte** *(anställd)*, **der/ein Erwachsene** *(vuxen)*, **der/ein Jugendliche** *(ungdom)*.

### Böjningstabell: "Deutsch" som person

| Kasus | Bestämd form (svag böjning) | Obestämd form (blandad böjning) |
| :--- | :--- | :--- |
| **Maskulin Nominativ** | **der Deutsche** *(tysken)* | **ein Deutscher** *(en tysk)* |
| **Maskulin Ackusativ** | **den Deutschen** | **einen Deutschen** |
| **Maskulin Dativ** | **dem Deutschen** | **einem Deutschen** |
| **Feminin Nominativ** | **die Deutsche** *(tyskan)* | **eine Deutsche** *(en tysk kvinna)* |
| **Plural Nominativ** | **die Deutschen** *(tyskarna)* | **Deutsche** / **viele Deutsche** |

Detta förklarar varför man säger:
* <span lang="de">Er ist **Deutscher**</span> (stark nollartikel: er ist ein Deutscher / Deutscher).
* <span lang="de">**Der Deutsche** wohnt in Berlin.</span>

---

## 3. Efter obestämda pronomen: "etwas Neues"

När ett adjektiv står efter orden **etwas** *(något)*, **nichts** *(inget)*, **viel** *(mycket)* eller **wenig** *(lite)* substantiveras det:
* Det skrivs med **stor bokstav**.
* Det får ändelsen **-es** (stark neutral böjning):

* <span lang="de">Haben Sie **etwas Neues** gehört?</span> *(Har ni hört något nytt?)*
* <span lang="de">Es gibt **nichts Besseres** als eine heiße Tasse Tee.</span> *(Det finns inget bättre än...)*
* <span lang="de">Ich wünsche dir **viel Schönes** für die Zukunft!</span> *(Jag önskar dig mycket vackert...)*

Undantag: Efter ordet **alles** *(allt)* böjs adjektivet svagt med **-e**:
* <span lang="de">Ich wünsche dir **alles Gute** zum Geburtstag!</span> *(Allt gott på födelsedagen!)*

## 10 autentiska exempel

1. <span lang="de">**Das Schwimmen** im kalten See ist sehr erfrischend.</span>  
   *(substantiverad infinitiv neutrum: das Schwimmen.)*
2. <span lang="de">Ich habe gestern mit einem **Bekannten** aus Hamburg telefoniert.</span>  
   *(substantiverat adjektiv i dativ maskulinum: einem Bekannten.)*
3. <span lang="de">Gibt es **etwas Wichtiges**, das wir heute besprechen müssen?</span>  
   *(etwas Wichtiges med stor bokstav och -es.)*
4. <span lang="de">Die **Angestellten** der Firma fordern faire Gehälter.</span>  
   *(substantiverat particip i plural: die Angestellten.)*
5. <span lang="de">Wir haben im Urlaub **viele Deutsche** und Schweizer getroffen.</span>  
   *(substantiverade nationaliteter i plural: Deutsche.)*
6. <span lang="de">**Das lange Warten** am Flughafen war ziemlich anstrengend.</span>  
   *(das Warten med attributivt adjektiv.)*
7. <span lang="de">Hinter der Tür hörte man ein leises **Flüstern**.</span>  
   *(substantiverad infinitiv: das Flüstern.)*
8. <span lang="de">Er hat **nichts Interessantes** zu diesem Thema beizutragen.</span>  
   *(nichts Interessantes.)*
9. <span lang="de">Der Film ist nur für **Erwachsene** geeignet.</span>  
   *(plural utan artikel: für Erwachsene.)*
10. <span lang="de">Ich wünsche Ihnen vom Herzen **alles Liebe** und **alles Gute**!</span>  
    *(fast gratulationsfras efter alles: alles Liebe / alles Gute.)*
