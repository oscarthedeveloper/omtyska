## Kärnan på en halv minut

I tyskan finns två grundläggande frågetyper:

1. **Ja/Nej-frågor (Verbet på plats 1 = V1)**:
   * Det finita verbet inleder meningen:
   * <span lang="de">**Kommst** du aus Schweden?</span> *(Kommer du från Sverige?)*
   * <span lang="de">**Trinken** Sie Kaffee?</span> *(Dricker Ni kaffe?)*
2. **Frågeordsfrågor (W-Fragen: Verbet på plats 2 = V2)**:
   * Frågeordet står på plats 1, och verbet följer omedelbart på plats 2:
   * <span lang="de">**Wo** **wohnst** du?</span> *(Var bor du?)*
   * <span lang="de">**Warum** **lernst** du Deutsch?</span> *(Varför lär du dig tyska?)*

Tyskan konstruerar aldrig frågor med hjälpor som engelskans "do you like" — påståendet ställs bara om direkt:  
*Påstående:* <span lang="de">Du trinkst Tee.</span> -> *Fråga:* <span lang="de">Trinkst du Tee?</span>

## 1. De centrala tyska frågeorden (W-Fragen)

| Frågeord | Betydelse | Exempel | Svar |
| :--- | :--- | :--- | :--- |
| <span lang="de">**Wer**</span> | Vem (nominativ) | <span lang="de">Wer ist das?</span> | Das ist Peter. |
| <span lang="de">**Wen**</span> | Vem (ackusativ) | <span lang="de">Wen suchst du?</span> | Ich suche den Lehrer. |
| <span lang="de">**Wem**</span> | Vem (dativ) | <span lang="de">Wem hilfst du?</span> | Ich helfe der Oma. |
| <span lang="de">**Was**</span> | Vad | <span lang="de">Was machst du?</span> | Ich koche. |
| <span lang="de">**Wo**</span> | Var (befintlighet) | <span lang="de">Wo bist du?</span> | Im Park. |
| <span lang="de">**Wohin**</span> | Vart (riktning) | <span lang="de">Wohin gehst du?</span> | In den Park. |
| <span lang="de">**Woher**</span> | Varifrån (ursprung) | <span lang="de">Woher kommst du?</span> | Aus Schweden. |
| <span lang="de">**Wann**</span> | När | <span lang="de">Wann beginnt der Film?</span> | Um acht Uhr. |
| <span lang="de">**Warum**</span> | Varför | <span lang="de">Warum lachst du?</span> | Weil es lustig ist. |
| <span lang="de">**Wie**</span> | Hur | <span lang="de">Wie geht es dir?</span> | Sehr gut, danke. |
| <span lang="de">**Wie viel**</span> | Hur mycket / hur många | <span lang="de">Wie viel kostet das?</span> | Zehn Euro. |

## 2. Wo, Wohin och Woher (Platsfrågorna)

Observera precisionen i tyskans platsfrågor:
* **Wo?** kräver **befintlighet** (ofta dativ):  
  <span lang="de">Wo ist das Buch? — Auf dem Tisch.</span>
* **Wohin?** kräver **rörelse mot ett mål** (ofta ackusativ):  
  <span lang="de">Wohin legst du das Buch? — Auf den Tisch.</span>
* **Woher?** kräver **ursprung** (ofta prepositionen *aus* eller *von* + dativ):  
  <span lang="de">Woher hast du das Buch? — Aus der Bibliothek.</span>

---

## 3. Frågor med sammansatta verb eller modalverb

När meningen innehåller två verb (finit hjälpverb/modalverb + infinitiv/supinum):
* Det finita verbet står på plats 1 eller 2.
* Det andra verbet skjuts **längst bak i frågan**:

```
   Ja/nej-fråga:
   (Kannst)  du mich morgen  [anrufen]?
   
   W-fråga:
   Wann  (kannst)  du mich  [anrufen]?
```

## 10 autentiska exempel

1. <span lang="de">**Sprechen** Sie Deutsch?</span>  
   *(V1 ja/nej-fråga i artigt tilltal: Sprechen först, Sie direkt efter.)*
2. <span lang="de">**Woher** kommen Sie? — Ich komme aus Stockholm.</span>  
   *(W-fråga om ursprung: Woher på plats 1, kommen på plats 2.)*
3. <span lang="de">**Wohin** fahrt ihr in den Sommerferien?</span>  
   *(Wohin för målriktning.)*
4. <span lang="de">**Haben** Sie einen Tisch für zwei Personen frei?</span>  
   *(V1 i restaurangsammanhang.)*
5. <span lang="de">**Wie viel** kostet eine Fahrkarte nach Berlin?</span>  
   *(Fråga om pris med Wie viel.)*
6. <span lang="de">**Warum** hast du mich gestern nicht angerufen?</span>  
   *(Warum + finit hjälpverb hast på plats 2 + supinum angerufen sist.)*
7. <span lang="de">**Können** Sie das bitte noch einmal wiederholen?</span>  
   *(Artig förfrågan med modalverbet können på plats 1.)*
8. <span lang="de">**Um wie viel Uhr** beginnt das Konzert?</span>  
   *(Hela frågefrasen "Um wie viel Uhr" bildar förfältet på plats 1!)*
9. <span lang="de">**Wem** gehört dieses Fahrrad hier?</span>  
   *(Fråga med wem i dativ eftersom gehören styr dativ.)*
10. <span lang="de">**Bist** du heute Abend zu Hause?</span>  
    *(sein i V1 ja/nej-fråga: Bist du...?)*
