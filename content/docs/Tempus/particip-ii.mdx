## Kärnan på en halv minut

Partizip II bildas enligt tre tydliga huvudregler:

1. **Svaga verb (Regelbundna)**:
```
   ge-  +  Stam  +  -t
```
   * <span lang="de">mach-en</span> -> <span lang="de">**ge**-mach-**t**</span>
   * <span lang="de">kauf-en</span> -> <span lang="de">**ge**-kauf-**t**</span>
   * *(Vid stam på -t/-d: ge-...-et: <span lang="de">arbeiten</span> -> <span lang="de">**ge**-arbeit-**et**</span>)*
2. **Starka verb (Vokalväxlande)**:
```
   ge-  +  Ändrad stam  +  -en
```
   * <span lang="de">sing-en</span> -> <span lang="de">**ge**-sung-**en**</span>
   * <span lang="de">find-en</span> -> <span lang="de">**ge**-fund-**en**</span>
   * <span lang="de">fahr-en</span> -> <span lang="de">**ge**-fahr-**en**</span>
3. **Två grupper som ALDRIG får ge-**:
   * Verb som slutar på **-ieren**: <span lang="de">studieren</span> -> <span lang="de">studier**t**</span> *(inte gestudiert!)*
   * Oseparerbara prefix (**be-, ver-, etc.**): <span lang="de">bezahlen</span> -> <span lang="de">bezahl**t**</span>, <span lang="de">verstehen</span> -> <span lang="de">verstand**en**</span>.

## 1. Översikt: Hur Partizip II bildas

| Kategori | Regel | Infinitiv | Partizip II | Betydelse |
| :--- | :--- | :--- | :--- | :--- |
| **Svagt standardverb** | ge- + stam + -t | <span lang="de">hören</span> | <span lang="de">**ge**hör**t**</span> | hört |
| **Svagt verb på -d/-t** | ge- + stam + -et | <span lang="de">warten</span> | <span lang="de">**ge**wart**et**</span> | väntat |
| **Starkt verb** | ge- + avljud + -en | <span lang="de">schreiben</span> | <span lang="de">**ge**schrieb**en**</span> | skrivit |
| **Separerbart svagt** | partikel + ge- + stam + -t | <span lang="de">einkaufen</span> | <span lang="de">ein**ge**kauf**t**</span> | handlat |
| **Separerbart starkt** | partikel + ge- + stam + -en | <span lang="de">aufstehen</span> | <span lang="de">auf**ge**stand**en**</span> | stigit upp |
| **Verb på -ieren** | stam + -t (INGET ge-) | <span lang="de">fotografieren</span> | <span lang="de">fotografier**t**</span> | fotograferat |
| **Oseparerbart svagt** | prefix + stam + -t (INGET ge-) | <span lang="de">erzählen</span> | <span lang="de">erzähl**t**</span> | berättat |
| **Oseparerbart starkt** | prefix + stam + -en (INGET ge-) | <span lang="de">gewinnen</span> | <span lang="de">gewonn**en**</span> | vunnit |

## 2. Varför får verb på "-ieren" inget "ge-"?

Verb som slutar på **-ieren** är oftast franska eller latinska lånord:
* <span lang="de">telefonieren, studieren, reparieren, reservieren, diskutieren</span>

I tyskan har dessa ord huvudbetoningen på den sista stavelsen (**-ie-**). Prefixet *ge-* kan bara läggas till om betoningen ligger på den första stavelsen. Därför får de **aldrig ge-**:

* <span lang="de">telefonieren</span> -> <span lang="de">Ich habe **telefoniert**.</span> *(aldrig getelefoniert)*
* <span lang="de">studieren</span> -> <span lang="de">Er hat in Berlin **studiert**.</span>

---

## 3. Placering av Partizip II i meningen

När du använder Partizip II för att bilda dåtid (perfekt):
* Hjälpverbet (<span lang="de">haben</span> eller <span lang="de">sein</span>) böjs på **position 2**.
* Partizip II placeras **orubbligt längst bak i hela huvudsatsen**:

```
   Ich  (habe)  gestern Abend einen wunderbaren Film  [gesehen].
        Hjälpverb (Pos. 2)                            Partizip II (Sist)
```

## 10 autentiska exempel

1. <span lang="de">Hast du deine Hausaufgaben schon **gemacht**?</span>  
   *(Svagt verb: ge-mach-t.)*
2. <span lang="de">Wir haben gestern sehr lange auf den Bus **gewartet**.</span>  
   *(Stam på -t -> ge-wart-et.)*
3. <span lang="de">Er hat einen langen Brief an seine Familie **geschrieben**.</span>  
   *(Starkt verb: ge-schrieb-en.)*
4. <span lang="de">Ich habe meine Freundin vom Bahnhof **abgeholt**.</span>  
   *(Separerbart svagt verb: ab-ge-holt.)*
5. <span lang="de">Wann seid ihr heute Morgen **aufgestanden**?</span>  
   *(Separerbart starkt verb med sein: auf-ge-stand-en.)*
6. <span lang="de">Sie hat fünf Jahre an der Humboldt-Universität **studiert**.</span>  
   *(-ieren verb utan ge-: studiert.)*
7. <span lang="de">Der Mechaniker hat das alte Auto schnell **repariert**.</span>  
   *(-ieren verb: repariert.)*
8. <span lang="de">Wer hat die Rechnung **bezahlt**?</span>  
   *(Oseparerbart prefix be- utan ge-: bezahlt.)*
9. <span lang="de">Ich habe die schwierige Frage sofort **verstanden**.</span>  
   *(Oseparerbart prefix ver- utan ge-: verstanden.)*
10. <span lang="de">Unsere Mannschaft hat das Spiel **gewonnen**.</span>  
    *(gewinnen slutar på -en: gewonnen.)*
