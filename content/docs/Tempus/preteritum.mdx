## Kärnan på en halv minut

I tyskan finns två dåtidstempus:
1. **Perfekt** (<span lang="de">Ich habe gemacht, Ich bin gefahren</span>): Används i **vardagligt tal** och personliga mejl.
2. **Präteritum** (<span lang="de">Ich machte, Ich fuhr</span>): Används i **skriftspråk, berättelser och tidningar**.

Det finns dock ett **stort undantag** där preteritum är normen även i talspråk:
* **sein** -> <span lang="de">**war**</span> (ich war, du warst, er war...)
* **haben** -> <span lang="de">**hatte**</span> (ich hatte, du hattest, er hatte...)
* **Modalverben** -> <span lang="de">**konnte**, **musste**, **wollte**, **durfte**, **sollte**</span>

Ingen tysk säger *"Ich bin gestern müde gewesen"* i vardagligt tal — alla säger: <span lang="de">**Ich war gestern müde**</span>!

---

## 1. Svaga verb i preteritum: Ändelsen -te

Svaga verb bildar preteritum genom att lägga till **-te** till verbstammen.  
Observera att **1:a och 3:e person singular är identiska och saknar personändelse**:

| Person | machen (att göra) | wohnen (att bo) | arbeiten (stam på -t) |
| :--- | :--- | :--- | :--- |
| **ich** | <span lang="de">mach-**te**</span> | <span lang="de">wohn-**te**</span> | <span lang="de">arbeit-**ete**</span> |
| **du** | <span lang="de">mach-**test**</span> | <span lang="de">wohn-**test**</span> | <span lang="de">arbeit-**etest**</span> |
| **er / sie / es** | <span lang="de">mach-**te**</span> *(identisk med ich!)* | <span lang="de">wohn-**te**</span> | <span lang="de">arbeit-**ete**</span> |
| **wir** | <span lang="de">mach-**ten**</span> | <span lang="de">wohn-**ten**</span> | <span lang="de">arbeit-**eten**</span> |
| **ihr** | <span lang="de">mach-**tet**</span> | <span lang="de">wohn-**tet**</span> | <span lang="de">arbeit-**etet**</span> |
| **sie / Sie** | <span lang="de">mach-**ten**</span> | <span lang="de">wohn-**ten**</span> | <span lang="de">arbeit-**eten**</span> |

---

## 2. Starka verb i preteritum: Vokalväxling

Starka verb har ingen *-te*-ändelse. De byter vokal i stammen, och har **ingen ändelse alls i 1:a och 3:e person singular**:

| Person | gehen (ging) | fahren (fuhr) | schreiben (schrieb) |
| :--- | :--- | :--- | :--- |
| **ich** | <span lang="de">**ging**</span> *(ingen ändelse)* | <span lang="de">**fuhr**</span> *(ingen ändelse)* | <span lang="de">**schrieb**</span> *(ingen ändelse)* |
| **du** | <span lang="de">ging-**st**</span> | <span lang="de">fuhr-**st**</span> | <span lang="de">schrieb-**st**</span> |
| **er / sie / es** | <span lang="de">**ging**</span> *(ingen ändelse)* | <span lang="de">**fuhr**</span> *(ingen ändelse)* | <span lang="de">**schrieb**</span> *(ingen ändelse)* |
| **wir** | <span lang="de">ging-**en**</span> | <span lang="de">fuhr-**en**</span> | <span lang="de">schrieb-**en**</span> |
| **ihr** | <span lang="de">ging-**t**</span> | <span lang="de">fuhr-**t**</span> | <span lang="de">schrieb-**t**</span> |
| **sie / Sie** | <span lang="de">ging-**en**</span> | <span lang="de">fuhr-**en**</span> | <span lang="de">schrieb-**en**</span> |

---

## 3. De oumbärliga formerna: war, hatte och modalverb

Dessa måste du kunna flytande även i vardagligt samtal:

| Infinitiv | 1:a person singular (ich) | 3:e person singular (er/sie/es) | Svenska |
| :--- | :--- | :--- | :--- |
| <span lang="de">**sein**</span> | <span lang="de">ich **war**</span> | <span lang="de">er **war**</span> | var |
| <span lang="de">**haben**</span> | <span lang="de">ich **hatte**</span> | <span lang="de">er **hatte**</span> | hade |
| <span lang="de">**können**</span> | <span lang="de">ich **konnte**</span> | <span lang="de">er **konnte**</span> | kunde (utan omljud!) |
| <span lang="de">**müssen**</span> | <span lang="de">ich **musste**</span> | <span lang="de">er **musste**</span> | måste / var tvungen (utan omljud!) |
| <span lang="de">**wollen**</span> | <span lang="de">ich **wollte**</span> | <span lang="de">er **wollte**</span> | ville |
| <span lang="de">**dürfen**</span> | <span lang="de">ich **durfte**</span> | <span lang="de">er **durfte**</span> | fick / hade lov till (utan omljud!) |
| <span lang="de">**sollen**</span> | <span lang="de">ich **sollte**</span> | <span lang="de">er **sollte**</span> | skulle / borde |

*Tips:* Lägg märke till att modalverben tappar sina omljud (*ö -> o, ü -> u*) i preteritum!

---

## 10 autentiska exempel

1. <span lang="de">Gestern **war** das Wetter wirklich herrlich.</span>  
   *(sein i preteritum: war.)*
2. <span lang="de">Ich **hatte** leider keine Zeit, dich anzurufen.</span>  
   *(haben i preteritum: hatte.)*
3. <span lang="de">Er **konnte** die schwierige Frage nicht beantworten.</span>  
   *(können i preteritum: konnte utan omljud.)*
4. <span lang="de">Es **war** einmal ein alter König in einem fernen Land.</span>  
   *(Klassisk sagoinledning i preteritum: Es war einmal.)*
5. <span lang="de">Wir **mussten** über eine Stunde auf den Zug warten.</span>  
   *(müssen i preteritum: mussten.)*
6. <span lang="de">Der Minister **erklärte** den Journalisten die neue Maßnahme.</span>  
   *(Skriftspråk i nyhetstext: erklärte.)*
7. <span lang="de">Sie **wollte** schon immer Ärztin werden.</span>  
   *(wollen i preteritum: wollte.)*
8. <span lang="de">Plötzlich **kam** ein Mann um die Ecke und **fragte** nach dem Weg.</span>  
   *(Berättande stil: starkt verb kam + svagt verb fragte.)*
9. <span lang="de">Wo **warst** du gestern um acht Uhr?</span>  
   *(du-form av sein i preteritum: warst.)*
10. <span lang="de">Die Kinder **durften** heute länger aufbleiben.</span>  
    *(dürfen i preteritum: durften.)*
