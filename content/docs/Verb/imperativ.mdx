## Kärnan på en halv minut

Imperativ har **tre former** beroende på tilltalet:

```
Verb                du-form (Kompis)      ihr-form (Kompisar)      Sie-form (Artigt tilltal)
---------------------------------------------------------------------------------------------
machen (göra)       Mach!                 Macht!                   Machen Sie!
kommen (komma)      Komm!                 Kommt!                   Kommen Sie!
warten (vänta)      Warte!                Wartet!                  Warten Sie!
sprechen (tala)     Sprich! (e->i)        Sprecht!                 Sprechen Sie!
sein (vara)         Sei!                  Seid!                    Seien Sie!
```

I du- och ihr-formerna **stryks pronomenet helt** (*Mach!* inte *Mach du!*). I den artiga formen måste **Sie alltid finnas med direkt efter verbet** (*Machen Sie!*).

---

## 1. Du-formen: Hur bildas den?

Utgå från presensformen för *du* och ta bort både **du** och ändelsen **-st**:

* <span lang="de">du machst</span> -> ta bort *du* och *-st* -> **Mach!**
* <span lang="de">du kommst</span> -> **Komm!**
* <span lang="de">du trinkst</span> -> **Trink!**

### När krävs ett extra "-e"?
* När verbstammen slutar på **-t, -d** eller **konsonant + m/n**:  
  <span lang="de">warten</span> (du wartest) -> **Warte!**  
  <span lang="de">atmen</span> (du atmest) -> **Atme!**  
  <span lang="de">öffnen</span> (du öffnest) -> **Öffne!**
* Vid verb på **-eln / -ern**:  
  <span lang="de">lächeln</span> -> **Lächle!** / **Lächele!**

---

## 2. Starka verb i imperativ: e -> i växling!

Här finns en viktig asymmetri mellan två olika starka verbgrupper:

1. **Verb med e -> i / ie-växling i presens BEHÅLLER växlingen i imperativ:**  
   * <span lang="de">geben</span> (du gibst) -> **Gib!** *(Ge!)*
   * <span lang="de">helfen</span> (du hilfst) -> **Hilf!** *(Hjälp!)*
   * <span lang="de">lesen</span> (du liest) -> **Lies!** *(Läs!)*
   * <span lang="de">nehmen</span> (du nimmst) -> **Nimm!** *(Ta!)*  
   *(Obs: Starka verb med e->i får ALDRIG ett extra -e i slutet: det heter Gib!, aldrig Gibe!)*

2. **Verb med omljud (a -> ä) TAPPAR omljudet i imperativ:**  
   * <span lang="de">fahren</span> (du fährst) -> **Fahr!** *(Kör! – inte fähr!)*
   * <span lang="de">schlafen</span> (du schläfst) -> **Schlaf!** *(Sov! – inte schläf!)*
   * <span lang="de">laufen</span> (du läufst) -> **Lauf!** *(Spring!)*

---

## 3. Särfallet "sein" och partikelverb

### Verbet sein (vara):
* Du: <span lang="de">**Sei** ruhig!</span> *(Var lugn!)*
* Ihr: <span lang="de">**Seid** vorsichtig!</span> *(Var försiktiga!)*
* Sie: <span lang="de">**Seien Sie** willkommen!</span> *(Var välkommen!)*

### Separerbara verb: Partikeln kastas allra sist!
* <span lang="de">aufstehen</span> -> **Steh** bitte sofort **auf**!
* <span lang="de">mitkommen</span> -> **Kommen Sie** doch **mit**!
* <span lang="de">anrufen</span> -> **Ruf** mich morgen **an**!

### Reflexiva verb: Pronomenet följer verbet
* <span lang="de">sich setzen</span> -> **Setz dich**! (du) / **Setzt euch**! (ihr) / **Setzen Sie sich**! (Sie)

---

## 4. Opersonliga uppmaningar på skyltar (Infinitiv)

I instruktioner, recept och officiella förbudsskyltar används mycket ofta **ren infinitiv** i stället för personböjd imperativ:
* <span lang="de">Bitte **nicht rauchen**!</span> *(Vänligen rök ej!)*
* <span lang="de">Hier **aussteigen**!</span> *(Avstigning här!)*
* <span lang="de">Türen **freihalten**!</span> *(Håll dörrarna fria!)*

---

## 10 autentiska exempel

1. <span lang="de">**Nimm** dir noch ein Stück Kuchen!</span>  
   *(du-imperativ av nehmen: nimm!)*
2. <span lang="de">**Fahr** bitte vorsichtig, die Straße ist glatt!</span>  
   *(fahren tappar omljudet: fahr!)*
3. <span lang="de">**Seien Sie** so freundlich und schließen Sie die Tür!</span>  
   *(artig Sie-form av sein och schließen.)*
4. <span lang="de">**Warte** kurz auf mich, ich bin gleich fertig!</span>  
   *(stam på -t kräver -e: Warte!)*
5. <span lang="de">**Kinder, seid** endlich leise und schlaft!</span>  
   *(ihr-form till flera barn: seid, schlaft!)*
6. <span lang="de">**Gib** mir bitte mal das Salz rüber!</span>  
   *(geben med e->i: Gib!)*
7. <span lang="de">**Helfen Sie** mir bitte, ich habe mich verlaufen!</span>  
   *(artig Sie-form: Helfen Sie!)*
8. <span lang="de">**Steht** bitte alle auf und begrüßt den Gast!</span>  
   *(ihr-form med partikelverb: Steht auf!)*
9. <span lang="de">**Mach** dir keine Sorgen, alles wird gut!</span>  
   *(vanlig du-imperativ: Mach!)*
10. <span lang="de">Bitte die Fenster bei Regen **schließen**!</span>  
    *(opersonlig skylt med ren infinitiv.)*
