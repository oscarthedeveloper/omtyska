## Kärnan på en halv minut

I tyskan är många verb sammansatta med en **förstavelse (partikel)**. Om partikeln är **betonad**, är verbet **separerbart** (*trennbar*):

* Infinitiv: <span lang="de">**auf**stehen</span> (stiga upp — betoningen ligger på *auf-*)
* I huvudsats klyvs verbet:
  * Stammen böjs på **position 2**.
  * Partikeln skjuts **längst bak**:
  * <span lang="de">Ich **stehe** jeden Morgen um sechs Uhr **auf**.</span>

```
   Position 1     Position 2 (Böjd stam)     Mittelfeld                   Satsens slut (Partikel)
   -----------------------------------------------------------------------------------------------
   Ich            rufe                       dich morgen                  AN.
   Wir            kaufen                     im Supermarkt                EIN.
   Der Zug        fährt                      pünktlich um zehn Uhr        AB.
```

---

## 1. De vanligaste separerbara partiklarna

Alla dessa partiklar är alltid betonade och separeras i huvudsats:

| Partikel | Betydelseidé | Exempelverb | Exempel i huvudsats |
| :--- | :--- | :--- | :--- |
| **ab-** | bort, avgång | <span lang="de">**ab**fahren</span> (avgå) | <span lang="de">Der Bus fährt um acht Uhr **ab**.</span> |
| **an-** | till, på, början | <span lang="de">**an**kommen</span> (anlända) | <span lang="de">Wann kommst du **an**?</span> |
| | kontakt | <span lang="de">**an**rufen</span> (ringa) | <span lang="de">Ich rufe dich später **an**.</span> |
| **auf-** | uppåt, öppet | <span lang="de">**auf**stehen</span> (stiga upp) | <span lang="de">Er steht früh **auf**.</span> |
| | | <span lang="de">**auf**machen</span> (öppna) | <span lang="de">Mach bitte das Fenster **auf**!</span> |
| **aus-** | ut, stängt | <span lang="de">**aus**steigen</span> (stiga av) | <span lang="de">Wir steigen hier **aus**.</span> |
| | | <span lang="de">**aus**machen</span> (släcka) | <span lang="de">Er macht das Licht **aus**.</span> |
| **ein-** | in | <span lang="de">**ein**kaufen</span> (handla) | <span lang="de">Ich kaufe im Markt **ein**.</span> |
| | | <span lang="de">**ein**steigen</span> (stiga på) | <span lang="de">Steigen Sie bitte **ein**!</span> |
| **mit-** | med | <span lang="de">**mit**kommen</span> (följa med) | <span lang="de">Kommst du heute **mit**?</span> |
| **vor-** | före, presentera | <span lang="de">**vor**stellen</span> (presentera) | <span lang="de">Ich stelle mich kurz **vor**.</span> |
| **zu-** | stänga, till | <span lang="de">**zu**hören</span> (lyssna) | <span lang="de">Hör mir bitte **zu**!</span> |

---

## 2. När separeras verbet INTE?

Verbet separeras **inte** i följande tre viktiga fall:

### 1. Tillsammans med ett modalverb (Infinitiv i slutet)
* <span lang="de">Ich muss morgen früh **aufstehen**.</span> *(Verbet förblir i ett stycke sist i satsen!)*

### 2. I en bisats (Verbet sist)
* I bisatser efter konjunktioner som *weil, dass, wenn* hamnar hela det böjda verbet allra sist i ett enda stycke:
* <span lang="de">Ich bin müde, weil ich heute so früh **aufstehe**.</span> *(inte stehe ... auf!)*

### 3. När partikeln är obetonad (Fast sammansatta verb)
* Förstavelserna **be-, emp-, ent-, er-, ge-, ver-, zer-** är **obetonade** och separeras **ALDRIG**:
* <span lang="de">bezahlen</span> -> <span lang="de">Ich **bezahle** die Rechnung</span> *(aldrig zahle ... be!)*
* <span lang="de">verstehen</span> -> <span lang="de">Ich **verstehe** das nicht</span> *(aldrig stehe ... ver!)*

---

## 3. Hur bildas dåtid (Perfekt)?

I perfekt stoppas ändelsemärket **-ge-** in **mitt emellan partikeln och stammen**:

```
   Partikel  +  ge-  +  Stam  +  -t / -en
```

* <span lang="de">einkaufen</span> -> <span lang="de">ein-**ge**-kauf-t</span>
* <span lang="de">anrufen</span> -> <span lang="de">an-**ge**-ruf-en</span>
* <span lang="de">aufstehen</span> -> <span lang="de">auf-**ge**-stand-en</span>

Mening i dåtid:  
<span lang="de">Ich habe dich gestern **angerufen**.</span>

## 10 autentiska exempel

1. <span lang="de">Der Wecker klingelt und ich **stehe** sofort **auf**.</span>  
   *(aufstehen i huvudsats: stehe på plats 2, auf sist.)*
2. <span lang="de">Wann **ruft** Peter seine Eltern **an**?</span>  
   *(W-fråga: ruft på plats 2, an sist.)*
3. <span lang="de">Wir **kaufen** heute fürs ganze Wochenende **ein**.</span>  
   *(einkaufen klyvs i huvudsats.)*
4. <span lang="de">Der Zug **fährt** in fünf Minuten **ab**.</span>  
   *(abfahren med partikeln ab sist.)*
5. <span lang="de">Bitte **machen** Sie die Tür **zu**, es zieht!</span>  
   *(zumachen i uppmaning: machen först, zu sist.)*
6. <span lang="de">Möchtest du heute Abend mit ins Kino **mitkommen**?</span>  
   *(Efter möchtest står verbet i infinitiv och förblir helt: mitkommen.)*
7. <span lang="de">Ich habe meine Freundin vom Flughafen **abgeholt**.</span>  
   *(Perfekt av abholen: ab-ge-holt.)*
8. <span lang="de">Er **zieht** sich schnell eine warme Jacke **an**.</span>  
   *(anziehen: zieht på plats 2, an sist.)*
9. <span lang="de">Ich weiß, dass er jeden Tag um sechs Uhr **aufsteht**.</span>  
   *(I bisats efter dass hålls verbet ihop sist i satsen: aufsteht.)*
10. <span lang="de">**Hören** Sie mir bitte genau **zu**!</span>  
    *(zuhören i imperativ: Hören Sie ... zu!)*
