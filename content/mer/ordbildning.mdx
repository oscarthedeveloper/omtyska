## Kärnan på en halv minut

I tyskan är substantivets slutändelse (suffix) den enskilt starkaste ledtråden till ordets genus:

```
1. FEMININA SUFFIX (100% ALLTID DIE):
   -ung     -> die Zeitung, die Wohnung, die Bedeutung, die Übung
   -heit    -> die Freiheit, die Wahrheit, die Gesundheit, die Krankheit
   -keit    -> die Möglichkeit, die Höflichkeit, die Einsamkeit
   -schaft  -> die Freundschaft, die Mannschaft, die Landschaft
   -tät     -> die Universität, die Realität, die Qualität
   -ion     -> die Station, die Tradition, die Situation

2. NEUTRALA SUFFIX (100% ALLTID DAS):
   -chen    -> das Mädchen, das Brötchen, das Häuschen (förminskningsord)
   -lein    -> das Fräulein, das Kindlein
   -ment    -> das Dokument, das Instrument, das Experiment
   -um      -> das Museum, das Zentrum, das Datum

3. MASKULINA SUFFIX (NÄSTAN ALLTID DER):
   -ismus   -> der Optimismus, der Realismus, der Tourismus
   -or      -> der Motor, der Reaktor, der Professor
   -er      -> der Lehrer, der Bäcker, der Computer (handlande person/verktyg)
```

## 1. De magiska verbprefixen

När du sätter ett oskiljaktigt prefix på ett verb förvandlas dess betydelse på regelbundna sätt:

| Prefix | Kärnbetydelse | Exempel med basverb |
| :--- | :--- | :--- |
| **ver-** | 1. Felaktighet / misstag<br />2. Förändring av tillstånd | <span lang="de">rechnen</span> (räkna) -> <span lang="de">sich **verrechnen**</span> (räkna fel)<br /><span lang="de">schlafen</span> -> <span lang="de">sich **verschlafen**</span> (försova sig)<br /><span lang="de">bessern</span> -> <span lang="de">**verbessern**</span> (förbättra) |
| **zer-** | Total förstörelse / sönder | <span lang="de">brechen</span> -> <span lang="de">**zerbrechen**</span> (bryta sönder i bitar)<br /><span lang="de">stören</span> -> <span lang="de">**zerstören**</span> (förstöra helt) |
| **be-** | Gör ett intransitivt verb transitivt (tar ackusativobjekt) | <span lang="de">antworten auf</span> (svara på) -> <span lang="de">etwas **beantworten**</span><br /><span lang="de">wohnen in</span> -> <span lang="de">ein Haus **bewohnen**</span> |
| **ent-** | Borttagande / avlägsnande / startpunkt | <span lang="de">decken</span> -> <span lang="de">**entdecken**</span> (täcka av -> upptäcka)<br /><span lang="de">spannen</span> -> <span lang="de">sich **entspannen**</span> (spänna av -> koppla av) |
| **miss-** | Negativt / felaktigt | <span lang="de">verstehen</span> -> <span lang="de">**missverstehen**</span> (missförstå)<br /><span lang="de">brauchen</span> -> <span lang="de">**missbrauchen**</span> (missbruka) |

## 2. Hur adjektiv bildas av substantiv och verb

* **-bar** = *möjlig att göra* (motsvarar engelskans *-able* / svenskans *-bar*):
  * <span lang="de">trinken</span> -> <span lang="de">trinkbar</span> *(drickbar)*
  * <span lang="de">essen</span> -> <span lang="de">essbar</span> *(ätbar)*
  * <span lang="de">lösen</span> -> <span lang="de">lösbar</span> *(lösbar / möjlig att lösa)*
* **-los** = *saknad av* (svenskans *-lös*):
  * <span lang="de">die Hoffnung</span> -> <span lang="de">hoffnungslos</span> *(hopplös)*
  * <span lang="de">die Arbeit</span> -> <span lang="de">arbeitslos</span> *(arbetslös)*
* **-reich** / **-arm** = *rik på / fattig på*:
  * <span lang="de">erfolgreich</span> *(framgångsrik)*, <span lang="de">kalorienarm</span> *(kalorisnål)*

---

## 3. Sammansatta substantiv och fogelement (Fugenlaute)

I sammansatta ord styrs genus **alltid av det sista ordet**:
* <span lang="de">die Autobahn</span> (das Auto + **die Bahn**)
* <span lang="de">das Wörterbuch</span> (die Wörter + **das Buch**)

Mellan orden skjuts ofta ett fogelement in för att underlätta uttalet:
* **Fugen-s:** <span lang="de">der Geburtstag</span> (die Geburt + **s** + der Tag), <span lang="de">das Arbeitszimmer</span>
* **Fugen-en:** <span lang="de">das Studentenleben</span> (der Student + **en** + das Leben)
