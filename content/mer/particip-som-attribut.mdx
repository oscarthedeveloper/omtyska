## Kärnan på en halv minut

Både **Partizip I** och **Partizip II** kan fungera som helt vanliga attributiva adjektiv direkt framför ett substantiv:

```
1. PARTIZIP I (Infinitiv + d)  ──> PÅGÅENDE AKTIV HANDLING
   lachen (skratta) -> lachend  -> "ein LACHENDES Kind" (ett skrattande barn)
   schlafen (sova)  -> schlafend -> "der SCHLAFENDE Hund" (den sovande hunden)

2. PARTIZIP II (ge- -t / -en)  ──> AVSLUTAD ELLER PASSIV HANDLING
   reparieren      -> repariert -> "das REPARIERTE Auto" (den reparerade bilen)
   schreiben       -> geschrieben -> "der GESCHRIEBENE Brief" (det skrivna brevet)
```

När de står framför ett substantiv måste de **alltid böjas med adjektivändelser** (-e, -en, -er, -es) enligt vanliga adjektivregler!

## 1. Jämförelse mellan Partizip I och Partizip II

| Verb | Partizip I (Aktiv / Samtidig) | Partizip II (Passiv / Avslutad) |
| :--- | :--- | :--- |
| **kochen** (koka) | <span lang="de">das **kochende** Wasser</span> *(det kokande vattnet [kokar nu])* | <span lang="de">das **gekochte** Ei</span> *(det kokta ägget [färdigkokt])* |
| **schließen** (stänga) | <span lang="de">die sich **schließende** Tür</span> *(dörren som stängs)* | <span lang="de">die **geschlossene** Tür</span> *(den stängda dörren)* |
| **sinken** (sjunka) | <span lang="de">die **sinkenden** Preise</span> *(de sjunkande priserna)* | <span lang="de">das **gesunkene** Schiff</span> *(det sjunkna skeppet)* |

## 2. Utbyggda participattribut (Erweiterte Partizipialattribute)

Detta är tyskans mest kända stilistiska konstruktion för att komprimera text. All bestämning till participet kilas in mellan artikeln och substantivet:

```
[Artikel]  +  [Inskjuten beskrivning]       +  [Particip]      +  [Substantiv]
Der        von vielen Touristen besuchte        alte               Kölner Dom...
Das        gestern von der Polizei gefundene                       Auto...
```

### Hur du packar upp konstruktionen:
1. Identifiera ytterkanterna: **artikeln** och **huvudsubstantivet** (*Das ... Auto*).
2. Gör om participet och dess bestämning till en vanlig **relativsats**:
   * <span lang="de">Das gestern von der Polizei gefundene Auto...</span>  
     -> <span lang="de">Das Auto, **das gestern von der Polizei gefunden wurde**...</span>

---

## 3. Gerundiv med "zu" (Måste-aspekt)

Om du sätter **zu** framför ett Partizip I får det betydelsen *som måste / bör göras*:
* <span lang="de">das **zu lösende** Problem</span> *(problemet som måste lösas)*
* <span lang="de">die **zu bezahlende** Rechnung</span> *(räkningen som ska betalas)*

Denna konstruktion motsvarar direkt passiversättningen *sein + zu + infinitiv*!
